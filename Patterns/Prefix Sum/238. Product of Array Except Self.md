# 238. Product of Array Except Self

**Difficulty:** Medium

---

# Problem Statement

Given an integer array `nums`, return an array `answer` such that

```
answer[i] = product of all elements of nums except nums[i]
```

### Conditions

- You **cannot use division**.
- The algorithm must run in **O(n)** time.
- The output array does **not** count as extra space.

---

# Examples

### Example 1

```text
Input:
nums = [1,2,3,4]

Output:
[24,12,8,6]
```

Explanation

```
Index 0 -> 2×3×4 = 24

Index 1 -> 1×3×4 = 12

Index 2 -> 1×2×4 = 8

Index 3 -> 1×2×3 = 6
```

---

### Example 2

```text
Input:
nums = [-1,1,0,-3,3]

Output:
[0,0,9,0,0]
```

---

# Approach 1 : Brute Force

## Idea

For every index,

- Multiply every other element.
- Skip the current index.

---

## Algorithm

For every index `i`

```
product = 1

For every index j

If i != j

product *= nums[j]
```

Store the product.

---

## Java Code

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;
        int[] ans = new int[n];

        for (int i = 0; i < n; i++) {

            int product = 1;

            for (int j = 0; j < n; j++) {

                if (i != j)
                    product *= nums[j];
            }

            ans[i] = product;
        }

        return ans;
    }
}
```

---

## Dry Run

```
nums = [1,2,3,4]

i = 0

product = 2×3×4 = 24

ans = [24]

------------------

i = 1

product = 1×3×4 = 12

ans = [24,12]

------------------

i = 2

product = 1×2×4 = 8

ans = [24,12,8]

------------------

i = 3

product = 1×2×3 = 6

ans = [24,12,8,6]
```

---

## Complexity

- Time : O(n²)
- Space : O(1) (excluding output array)

# Approach 2 : Prefix Product + Suffix Product Arrays

## Idea

For every index,

```
Answer = Product of all elements before it
       × Product of all elements after it
```

So create

- Prefix Product Array
- Suffix Product Array

---

## Prefix Product

```
prefix[i]

= product of all elements before i
```

Example

```
nums

[1,2,3,4]

prefix

[1,1,2,6]
```

Explanation

```
prefix[0] = 1

prefix[1] = 1

prefix[2] = 1×2 = 2

prefix[3] = 1×2×3 = 6
```

---

## Suffix Product

```
suffix[i]

= product of all elements after i
```

Example

```
suffix

[24,12,4,1]
```

Explanation

```
suffix[3] = 1

suffix[2] = 4

suffix[1] = 3×4 = 12

suffix[0] = 2×3×4 = 24
```

---

## Final Answer

```
answer[i]

= prefix[i] × suffix[i]
```

Example

```
prefix

[1,1,2,6]

suffix

[24,12,4,1]

Multiply

24
12
8
6
```

---

## Java Code

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;

        int[] prefix = new int[n];
        int[] suffix = new int[n];
        int[] ans = new int[n];

        prefix[0] = 1;

        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i - 1] * nums[i - 1];
        }

        suffix[n - 1] = 1;

        for (int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] * nums[i + 1];
        }

        for (int i = 0; i < n; i++) {
            ans[i] = prefix[i] * suffix[i];
        }

        return ans;
    }
}
```

---

## Dry Run

```
nums

[1,2,3,4]

-------------------

Prefix

[1,1,2,6]

-------------------

Suffix

[24,12,4,1]

-------------------

Answer

24
12
8
6
```

---

## Complexity

- Time : O(n)
- Space : O(n)

# Approach 3 : Optimal (O(1) Extra Space)

## Idea

Instead of storing both prefix and suffix arrays,

Use the answer array itself to store prefix products.

Then traverse from the right while maintaining a suffix product.

---

## Step 1

Store prefix products inside answer.

Example

```
nums

[1,2,3,4]
```

Initially

```
answer

[1,1,1,1]
```

Build prefix

```
answer

[1,1,2,6]
```

---

## Step 2

Maintain

```
suffix = 1
```

Traverse from right.

```
answer[i] *= suffix

suffix *= nums[i]
```

---

## Dry Run

### Initial

```
nums

[1,2,3,4]

answer

[1,1,2,6]

suffix = 1
```

---

### i = 3

```
answer[3]

6 × 1 = 6

suffix

1 × 4 = 4
```

answer

```
[1,1,2,6]
```

---

### i = 2

```
answer[2]

2 × 4 = 8

suffix

4 × 3 = 12
```

answer

```
[1,1,8,6]
```

---

### i = 1

```
answer[1]

1 × 12 = 12

suffix

12 × 2 = 24
```

answer

```
[1,12,8,6]
```

---

### i = 0

```
answer[0]

1 × 24 = 24
```

Final

```
[24,12,8,6]
```

---

## Java Code

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {

        int n = nums.length;

        int[] ans = new int[n];

        ans[0] = 1;

        // Prefix products
        for (int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }

        // Suffix product
        int suffix = 1;

        for (int i = n - 1; i >= 0; i--) {

            ans[i] *= suffix;

            suffix *= nums[i];
        }

        return ans;
    }
}
```

---

## Complexity

- Time : O(n)
- Space : O(1)

(Output array is **not** counted as extra space.)

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| Brute Force | O(n²) | O(1) |
| Prefix + Suffix Arrays | O(n) | O(n) |
| Prefix + Running Suffix (Optimal) | O(n) | O(1) |

---

# Why can't we use division?

Example

```
nums = [1,2,0,4]
```

Total product becomes

```
0
```

Now dividing by an element does not work because division by zero is undefined.

Therefore, the problem explicitly asks for a solution **without using division**.

---

# Key Interview Points

- Do **not** use division.
- Store prefix products in the answer array.
- Maintain a running suffix product while traversing from right.
- Multiply prefix and suffix to get the answer.
- The output array is **not counted** as extra space.
- Optimal solution runs in **O(n)** time and **O(1)** extra space.
