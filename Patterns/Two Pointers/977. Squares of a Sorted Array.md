# LeetCode 977 — Squares of a Sorted Array

## Problem

Given a sorted integer array `nums` in non-decreasing order, return an array of the squares of each number also sorted in non-decreasing order.

---

## Examples

### Example 1

```text
Input:
nums = [-4,-1,0,3,10]

Output:
[0,1,9,16,100]
```

Explanation:

```text
Squares:
[16,1,0,9,100]

After sorting:
[0,1,9,16,100]
```

---

### Example 2

```text
Input:
nums = [-7,-3,2,3,11]

Output:
[4,9,9,49,121]
```

---

## Key Observation

Negative numbers become positive after squaring.

```text
-7² = 49
-3² = 9
```

The largest square will always come from either:

* Leftmost element
* Rightmost element

So we can use **Two Pointers**.

---

## Approach (Two Pointers)

* `l` → start of array
* `r` → end of array
* `idx` → last position of result array

Compare:

```text
nums[l]²
nums[r]²
```

Place the larger square at `res[idx]`.

---

Input:

```text
nums = [-4,-1,0,3,10]
```

l = 0

### Step 1

```text

(10)² = 100
```

100 is larger.

```text
res = [_,_,_,_,100]

idx--
```

### Step 2

```text

```

16 is larger.

```text

```

```text
(-1)² = 1
(3)² = 9
```

9 is larger.

```text

idx--
```

---

### Step 4

```text
(-1)² = 1
(0)² = 0
```

1 is larger.

```text
res = [_,1,9,16,100]

```

```text
0² = 0
```

```text
res = [0,1,9,16,100]
```

✅ Answer found.

## Code

```java
class Solution {
    public int[] sortedSquares(int[] nums) {

        int n = nums.length;
        int[] res = new int[n];

        int l = 0;
        int r = n - 1;
        int idx = n - 1;

        while (l <= r) {

            int leftSquare = nums[l] * nums[l];
            int rightSquare = nums[r] * nums[r];

            if (leftSquare > rightSquare) {
                res[idx--] = leftSquare;
                l++;
            } else {
                res[idx--] = rightSquare;
                r--;
            }
        }

        return res;
    }
}
```

## Interview Tip

A common mistake is:

```java
square all elements
sort again
```

which takes:

```text
O(N log N)
```

Using Two Pointers leverages the sorted property and achieves:

```text
O(N)
```

which is the expected solution.
