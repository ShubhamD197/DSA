# LeetCode 26 — Remove Duplicates from Sorted Array

## Idea

Since the array is already **sorted**, duplicates will always be adjacent.

Use:

* `i` → points to last unique element
* `j` → scans the array

Whenever we find a new unique element, place it at the next position.

---

# Code

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int i = 0;

        for (int j = 1; j < nums.length; j++) {
            if (nums[i] != nums[j]) {
                i++;
                nums[i] = nums[j];
            }
        }

        return i + 1;
    }
}
```

---

# Dry Run

Input:

```text
nums = [1,1,2,2,3]
```

Initial:

```text

```

| j | nums[j] | Action                  | Array       |
| - | ------- | ----------------------- | ----------- |
| 1 | 1       | Duplicate               | [1,1,2,2,3] |

| 3 | 2       | Duplicate               | [1,2,2,2,3] |
| 4 | 3       | Unique → i++, nums[i]=3 | [1,2,3,2,3] |

Final:

```text
i = 2
```

Return:

```text
i + 1 = 3
```

First 3 elements are:

```text
[1,2,3]
```

# Why It Works

`i` always stores the position of the **last unique element**.

When a new unique value is found:

```java
i++;
nums[i] = nums[j];
```

This shifts all unique elements to the front of the array.

```text
Time  : O(N)

```

# Pattern

```text
Two Pointers
```

One pointer reads (`j`), one pointer writes (`i`). This is a very common pattern for in-place array problems.
