# 104. Maximum Depth of Binary Tree

**Difficulty:** Easy

---

# Problem Statement

Given the `root` of a binary tree, return its **maximum depth**.

The **maximum depth** is the number of nodes along the longest path from the root node down to the farthest leaf node.

---

## Example 1

```text
Input:

        3
       / \
      9  20
         / \
        15  7

Output:
3
```

Explanation

```text
Longest path:

3 -> 20 -> 15

Depth = 3
```

---

## Example 2

```text
Input:

    1
     \
      2

Output:
2
```

---

# Approach 1 : Recursive DFS (Most Common)

## Idea

For every node:

```text
Depth of current node

=
1 + max(left depth, right depth)
```

Why?

- Current node contributes `1`
- Then take the deeper subtree

---

## Recursive Formula

```java
maxDepth(node)
=
1 + max(
    maxDepth(node.left),
    maxDepth(node.right)
)
```

### Base Case

```java
if(node == null)
    return 0;
```

---

---

## Java Code

```java
class Solution {
    public int maxDepth(TreeNode root) {

        if (root == null)
            return 0;

        return 1 + Math.max(
                maxDepth(root.left),
                maxDepth(root.right)
        );
    }
}
```

---

## Complexity

### Time

```text
O(n)
```

Every node is visited once.

### Space

```text
O(h)
```

Where `h` is tree height (recursion stack).

- Balanced Tree → O(log n)
- Skewed Tree → O(n)

# Approach 2 : Iterative DFS Using Stack

## Idea

Instead of recursion,

store:

```text
(node, depth)
```

inside a stack.

Keep updating maximum depth.

---

## Algorithm

1. Push root with depth 1.
2. Pop node.
3. Update answer.
4. Push children with depth + 1.
5. Continue until stack becomes empty.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int maxDepth(TreeNode root) {

        if (root == null)
            return 0;

        Stack<Pair> stack = new Stack<>();

        stack.push(new Pair(root, 1));

        int maxDepth = 0;

        while (!stack.isEmpty()) {

            Pair current = stack.pop();

            TreeNode node = current.node;
            int depth = current.depth;

            maxDepth = Math.max(maxDepth, depth);

            if (node.left != null)
                stack.push(new Pair(node.left, depth + 1));

            if (node.right != null)
                stack.push(new Pair(node.right, depth + 1));
        }

        return maxDepth;
    }
}

class Pair {
    TreeNode node;
    int depth;

    Pair(TreeNode node, int depth) {
        this.node = node;
        this.depth = depth;
    }
}
```

# Approach 3 : BFS (Level Order Traversal)

## Idea

Each level contributes one depth.

Count how many levels exist.

---

## Visualization

```text
Level 1

        3

----------------

Level 2

      9   20

----------------

Level 3

      15   7
```

Total Levels = 3

Answer = 3

---

## Algorithm

1. Add root to queue.
2. Process one level at a time.
3. Increase depth after every level.
4. Return final depth.

---

## Dry Run

### Initial

```text
Queue

[3]

depth = 0
```

---

### Level 1

```text

Process 3

Queue

[9,20]

depth = 1
```

---

### Level 2

```text
size = 2

Process 9
Process 20

Queue

[15,7]

depth = 2
```

---

### Level 3

```text
size = 2

Process 15
Process 7

Queue empty

depth = 3
```

Answer = 3

---

## Java Code

```java
import java.util.*;

class Solution {

    public int maxDepth(TreeNode root) {

        if (root == null)
            return 0;

        Queue<TreeNode> queue = new LinkedList<>();

        queue.offer(root);

        int depth = 0;

        while (!queue.isEmpty()) {

            int size = queue.size();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            depth++;
        }

        return depth;
    }
}
```

---

## Complexity

### Time

```text
O(n)
```

### Space

```text
O(n)
```

Queue may contain an entire level.

# Interview Follow-Up

### Minimum Depth vs Maximum Depth

For Maximum Depth:

```java
1 + Math.max(left, right)
```

For Minimum Depth:

```java
1 + Math.min(left, right)
```

BUT handle null children carefully.

---

# Pattern Recognition

Whenever the question asks:

```text
Height of Tree
Maximum Depth
Longest Root-to-Leaf Path
```

Think:

```java
1 + max(leftHeight, rightHeight)
```

This is one of the most important Binary Tree recursion patterns.

# Optimal Solution (Interview Answer)

```java
class Solution {
    public int maxDepth(TreeNode root) {

        if (root == null)
            return 0;

        return 1 + Math.max(
                maxDepth(root.left),
                maxDepth(root.right)
        );
    }
}
```

### Complexity

```text
Time  : O(n)
Space : O(h)
```

where `h` is the height of the tree.
