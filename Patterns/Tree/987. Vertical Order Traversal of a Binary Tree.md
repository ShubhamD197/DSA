# 987. Vertical Order Traversal of a Binary Tree

**Difficulty:** Hard

---

# Problem Statement

Given the `root` of a binary tree, calculate the **vertical order traversal** of the binary tree.

For each node:

- Left child → column - 1
- Right child → column + 1
- Root starts at `(row = 0, col = 0)`

### Sorting Rules

Nodes are sorted by:

1. **Column** (left to right)
2. **Row** (top to bottom)
3. **Value** (ascending, if same row and same column)

Return the vertical traversal.

# Approach : DFS + Sorting (Optimal)

## Idea

Every node has

- Row
- Column
- Value

Store all nodes as

```text
(column, row, value)
```

After DFS,

sort them according to the required rules.

Finally,

group nodes by column.

# DFS Traversal

Whenever we visit a node

Store

```text
(column,row,node.val)
```

Recursive calls

```text
Left

row + 1

column - 1
```

```text
Right

row + 1

column + 1
```

# Sorting Rule

Sort by

### 1. Column

Smaller column first

```text
-2
-1
0
1
2
```

---

### 2. Row

If columns are same

Higher node first

```text
Row

0

1

2
```

---

### 3. Value

If

```text
column same

AND

row same
```

Smaller value first.

---

# Algorithm

1. Perform DFS.
2. Store

```text
(column,row,value)
```

3. Sort

```
Column

↓

Row

↓

Value
```

4. Traverse sorted list.
5. Whenever column changes,
   create a new list.
6. Return result.

# Java Code

```java
import java.util.*;

class Solution {

    List<int[]> nodes = new ArrayList<>();

    public List<List<Integer>> verticalTraversal(TreeNode root) {

        dfs(root, 0, 0);

        Collections.sort(nodes, (a, b) -> {

            if (a[0] != b[0])
                return a[0] - b[0];

            if (a[1] != b[1])
                return a[1] - b[1];

            return a[2] - b[2];
        });

        List<List<Integer>> answer = new ArrayList<>();

        int previousColumn = Integer.MIN_VALUE;

        for (int[] node : nodes) {

            int column = node[0];
            int value = node[2];

            if (column != previousColumn) {

                answer.add(new ArrayList<>());

                previousColumn = column;
            }

            answer.get(answer.size() - 1).add(value);
        }

        return answer;
    }

    private void dfs(TreeNode node, int row, int column) {

        if (node == null)
            return;

        nodes.add(new int[]{column, row, node.val});

        dfs(node.left, row + 1, column - 1);

        dfs(node.right, row + 1, column + 1);
    }
}
```

# Why can't we simply use BFS?

A normal BFS groups nodes level by level, but it **does not automatically satisfy** the third sorting rule.

Example

```text
        1
       / \
      2   3
       \ /
        6 5
```

Coordinates

```text
6

Row = 2

Column = 0

----------------

5

Row = 2

Column = 0
```

Both nodes have the **same row** and **same column**.

The required output is

```text
[1,5,6]
```

because `5 < 6`.

A simple BFS would visit `6` before `5`, producing

```text
[1,6,5]
```

which is incorrect.

Therefore, we must sort by

1. Column
2. Row
3. Value

# Key Interview Points

- Each node is assigned a `(row, column)` coordinate.
- Store every node as `(column, row, value)`.
- Sort by **column → row → value**.
- Nodes sharing the same row and column are ordered by their value.
- DFS is used to collect coordinates, while sorting guarantees the required ordering.
- Overall complexity is **O(n log n)** because of sorting.
