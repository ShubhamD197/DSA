# 112. Path Sum

**Difficulty:** Easy

---

# Problem Statement

Given the `root` of a binary tree and an integer `targetSum`, return `true` if the tree has a **root-to-leaf path** such that adding up all the values along the path equals `targetSum`.

A **leaf node** is a node with **no left and no right child**.

---

# Example 1

```text
Input

targetSum = 22

              5
            /   \
           4     8
          /     / \
         11    13  4
        /  \        \
       7    2        1

Output

true
```

Explanation

Root → Leaf Path

```text
5 → 4 → 11 → 2

Sum

5 + 4 + 11 + 2 = 22
```

---

# Example 2

```text
Input

targetSum = 5

      1
     / \
    2   3

Output

false
```

Possible paths

```text
1 → 2 = 3

1 → 3 = 4
```

No path equals `5`.

---

# Example 3

```text
Input

root = []

targetSum = 0

Output

false
```

---

# Approach 1 : Recursive DFS (Subtract Target)

## Idea

Instead of calculating the running sum,

subtract the current node's value from `targetSum`.

When we reach a leaf node,

check whether the remaining target becomes `0`.

---

## Algorithm

1. If the tree is empty, return `false`.
2. Subtract the current node's value from `targetSum`.
3. If the current node is a leaf:
   - Return `true` if `targetSum == node.val`.
4. Otherwise, recursively check the left and right subtrees.

---

## Java Code

```java
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {

        if (root == null)
            return false;

        if (root.left == null && root.right == null)
            return targetSum == root.val;

        return hasPathSum(root.left, targetSum - root.val) ||
               hasPathSum(root.right, targetSum - root.val);
    }
}
```

# Approach 2 : DFS (Running Sum)

## Idea

Maintain the sum from the root to the current node.

Whenever a leaf node is reached,

compare the running sum with `targetSum`.

---

## Algorithm

1. Start with `currentSum = 0`.
2. Add the current node's value.
3. If the current node is a leaf:
   - Compare `currentSum` with `targetSum`.
4. Otherwise, continue recursively.

---

## Java Code

```java
class Solution {

    public boolean hasPathSum(TreeNode root, int targetSum) {
        return dfs(root, 0, targetSum);
    }

    private boolean dfs(TreeNode node, int currentSum, int targetSum) {

        if (node == null)
            return false;

        currentSum += node.val;

        if (node.left == null && node.right == null)
            return currentSum == targetSum;

        return dfs(node.left, currentSum, targetSum) ||
               dfs(node.right, currentSum, targetSum);
    }
}
```

# Approach 3 : Iterative DFS (Stack)

## Idea

Use a stack instead of recursion.

Each stack entry stores:

- Current node
- Current path sum

Whenever a leaf node is popped,

check if its sum equals `targetSum`.

---

## Java Code

```java
import java.util.*;

class Solution {

    public boolean hasPathSum(TreeNode root, int targetSum) {

        if (root == null)
            return false;

        Stack<TreeNode> nodeStack = new Stack<>();
        Stack<Integer> sumStack = new Stack<>();

        nodeStack.push(root);
        sumStack.push(root.val);

        while (!nodeStack.isEmpty()) {

            TreeNode node = nodeStack.pop();
            int currentSum = sumStack.pop();

            if (node.left == null && node.right == null &&
                currentSum == targetSum)
                return true;

            if (node.right != null) {
                nodeStack.push(node.right);
                sumStack.push(currentSum + node.right.val);
            }

            if (node.left != null) {
                nodeStack.push(node.left);
                sumStack.push(currentSum + node.left.val);
            }
        }

        return false;
    }
}
```

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| Recursive DFS (Subtract Target) | O(n) | O(h) |
| Recursive DFS (Running Sum) | O(n) | O(h) |
| Iterative DFS (Stack) | O(n) | O(h) |

---

# Why is checking only at the leaf important?

Consider

```text
      5
     /
    4
```

Target

```text
5
```

At the root,

the sum is already `5`.

However,

the path has **not ended** because the root is **not a leaf**.

The answer must be **false**.

A valid path must always be a **root-to-leaf** path.

---

# Key Interview Points

- A valid path must start at the **root** and end at a **leaf**.
- The recursive subtraction approach is the simplest and most commonly used solution.
- Always check the target **only at a leaf node**.
- DFS naturally explores all root-to-leaf paths.
- Both recursive and iterative DFS solutions run in **O(n)** time.
