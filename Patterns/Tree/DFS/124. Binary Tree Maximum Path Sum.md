# 124. Binary Tree Maximum Path Sum

**Difficulty:** Hard

---

# Problem Statement

A **path** in a binary tree is a sequence of nodes where each pair of adjacent nodes is connected by an edge.

A path:

- Can start at **any node**.
- Can end at **any node**.
- Must contain at least one node.
- Does **not** need to pass through the root.
- Cannot visit the same node twice.

Return the **maximum path sum**.

---

# Example 1

```text
Input

      1
     / \
    2   3

Output

6
```

Explanation

```text
Maximum Path

2 → 1 → 3

Sum

2 + 1 + 3 = 6
```

---

# Example 2

```text
Input

          -10
          /  \
         9   20
            /  \
           15   7

Output

42
```

Explanation

```text
Maximum Path

15 → 20 → 7

Sum

15 + 20 + 7 = 42
```

Notice

The path does **NOT** include the root.

---

# Key Observation

For every node,

there are **two different values** to consider.

### 1. Path Through Current Node

This path uses:

```text
Left Gain

↓

Current Node

↓

Right Gain
```

```text
left + node + right
```

This path **cannot** be returned to the parent because it branches into two directions.

It is only used to update the global maximum.

---

### 2. Gain Returned to Parent

A parent can only continue through **one child**.

So we return

```text
node + max(left, right)
```

Only one side can be extended upward.

---

# Approach : DFS (Optimal)

## Idea

For every node,

compute

```text
Maximum gain from left subtree

Maximum gain from right subtree
```

Ignore negative gains because they reduce the path sum.

```text
leftGain = max(0, left)

rightGain = max(0, right)
```

Then

Update answer

```text
leftGain + node.val + rightGain
```

Return

```text
node.val + max(leftGain, rightGain)
```

---

# Algorithm

1. Initialize answer as negative infinity.
2. Perform DFS.
3. Get left gain.
4. Get right gain.
5. Ignore negative gains.
6. Update global answer.
7. Return the maximum gain to the parent.

---

# Java Code

```java
class Solution {

    int maxSum = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {

        dfs(root);

        return maxSum;
    }

    private int dfs(TreeNode node) {

        if (node == null)
            return 0;

        int leftGain = Math.max(0, dfs(node.left));
        int rightGain = Math.max(0, dfs(node.right));

        int currentPath = leftGain + node.val + rightGain;

        maxSum = Math.max(maxSum, currentPath);

        return node.val + Math.max(leftGain, rightGain);
    }
}
```

# Why Ignore Negative Values?

Suppose

```text
      5
     /
   -10
```

Using

```text
5 + (-10)

=

-5
```

The path becomes smaller.

Instead,

ignore it.

```text
leftGain = max(0,-10)

=

0
```

Now

```text
Current Path

5
```

This gives a larger sum.

# Why Return Only One Side?

Suppose

```text
        20
       /  \
     15    7
```

To compute the answer **at node 20**, we can use

```text
15

↓

20

↓

7
```

But when returning to the parent,

the path cannot split into both children.

The parent can only continue through **one branch**.

So we return

```text
20 + max(15,7)

=

35
```

Not

```text
42
```

# Key Interview Points

- The path **can start and end at any node**.
- The path **does not have to pass through the root**.
- Ignore negative subtree gains using:

```java
Math.max(0, dfs(node))
```

- Update the global answer using:

```text
leftGain + node.val + rightGain
```

- Return only **one side** to the parent:

```text
node.val + max(leftGain, rightGain)
```

- Every node is processed exactly once, resulting in **O(n)** time complexity.
