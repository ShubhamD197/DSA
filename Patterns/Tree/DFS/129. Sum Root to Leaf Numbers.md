# 129. Sum Root to Leaf Numbers

**Difficulty:** Medium

---

# Problem Statement

You are given the `root` of a binary tree containing digits from **0 to 9**.

Each **root-to-leaf** path represents a number.

For every node:

- Append its digit to the current number.
- Return the sum of all root-to-leaf numbers.

---

# Example 1

```text
Input

      1
     / \
    2   3

Output

25
```

Explanation

Root-to-leaf numbers

```text
1 → 2

Number = 12

----------------

1 → 3

Number = 13
```

Total

```text
12 + 13 = 25
```

---

# Example 2

```text
Input

        4
       / \
      9   0
     / \

```

Numbers

```text
491

----------------

```

Total

```text

```

# Approach 1 : Recursive DFS (Build Number)

## Idea

Instead of storing digits separately,

build the current number while traversing.

For every node,

```text
currentNumber = currentNumber × 10 + node.val
```

Whenever a leaf node is reached,

return the completed number.

---

## Algorithm

1. If node is null, return 0.
2. Update the current number.
3. If the node is a leaf:
   - Return the current number.
4. Otherwise:
   - Return the sum from the left subtree and right subtree.

---

## Java Code

```java
class Solution {

    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int currentNumber) {

        if (node == null)
            return 0;

        currentNumber = currentNumber * 10 + node.val;

        if (node.left == null && node.right == null)
            return currentNumber;

        return dfs(node.left, currentNumber)
                + dfs(node.right, currentNumber);
    }
}
```

## Complexity

- Time : **O(n)**
- Space : **O(h)**

Where `h` is the height of the tree.

# Approach 2 : DFS (Using Global Sum)

## Idea

Instead of returning values,

maintain a global answer.

Whenever a leaf node is reached,

add the current number to the answer.

---

## Java Code

```java
class Solution {

    int sum = 0;

    public int sumNumbers(TreeNode root) {

        dfs(root, 0);

        return sum;
    }

    private void dfs(TreeNode node, int currentNumber) {

        if (node == null)
            return;

        currentNumber = currentNumber * 10 + node.val;

        if (node.left == null && node.right == null) {

            sum += currentNumber;
            return;
        }

        dfs(node.left, currentNumber);
        dfs(node.right, currentNumber);
    }
}
```

---

# Approach 3 : Iterative DFS (Stack)

## Idea

Use a stack.

Each stack entry stores:

- Current node
- Current number formed so far

Whenever a leaf node is popped,

add its number to the answer.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int sumNumbers(TreeNode root) {

        if (root == null)
            return 0;

        int total = 0;

        Stack<TreeNode> nodeStack = new Stack<>();
        Stack<Integer> numberStack = new Stack<>();

        nodeStack.push(root);
        numberStack.push(root.val);

        while (!nodeStack.isEmpty()) {

            TreeNode node = nodeStack.pop();
            int current = numberStack.pop();

            if (node.left == null && node.right == null)
                total += current;

            if (node.right != null) {
                nodeStack.push(node.right);
                numberStack.push(current * 10 + node.right.val);
            }

            if (node.left != null) {
                nodeStack.push(node.left);
                numberStack.push(current * 10 + node.left.val);
            }
        }

        return total;
    }
}
```

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| Recursive DFS (Return Sum) | O(n) | O(h) |

| Iterative DFS (Stack) | O(n) | O(h) |

---

# Why do we multiply by 10?

Suppose the current number is

```text
49
```

Next digit

```text
5
```

The new number becomes

```text
49 × 10 + 5

↓

490 + 5

↓

495
```

Each new digit is appended to the right of the existing number.

---

# Key Interview Points

- Every **root-to-leaf path** forms a decimal number.
- Build the number using:

  ```text
  current = current × 10 + node.val
  ```

- Add the number **only when a leaf node is reached**.
- DFS is the most natural solution because it follows root-to-leaf paths.
- Both recursive and iterative DFS solutions run in **O(n)** time.
