# 103. Binary Tree Zigzag Level Order Traversal

**Difficulty:** Medium

---

# Problem Statement

Given the `root` of a binary tree, return the **zigzag level order traversal** of its nodes' values.

The traversal alternates between:

- **Left → Right**
- **Right → Left**

for each consecutive level.

---

```text
        15   7

Output:

]
```

# Approach 1 : BFS (Queue + Reverse Every Alternate Level)

## Idea

Perform a normal **Level Order Traversal (BFS)**.

For every level:

- Collect nodes from left to right.
- If the current level should be traversed right to left,
  reverse the collected list before adding it to the answer.

---

## Algorithm

1. If root is `null`, return an empty list.
2. Create a queue and insert the root.
3. Maintain a boolean `leftToRight = true`.
4. Process one level at a time.
5. If `leftToRight` is `false`, reverse the current level.
6. Add the level to the result.
7. Toggle the direction.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {

        List<List<Integer>> answer = new ArrayList<>();

        if (root == null)
            return answer;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        boolean leftToRight = true;

        while (!queue.isEmpty()) {

            int size = queue.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                level.add(node.val);

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            if (!leftToRight)
                Collections.reverse(level);

            answer.add(level);

            leftToRight = !leftToRight;
        }

        return answer;
    }
}
```

# Approach 2 : BFS (Deque - No Reverse)

## Idea

Instead of reversing every alternate level,

use a `LinkedList` (Deque).

- Left → Right
  - Insert at the end.
- Right → Left
  - Insert at the beginning.

This avoids the reverse operation.

---

## Algorithm

1. Perform normal BFS.
2. Maintain a direction flag.
3. For each node:
   - If left to right → `addLast()`
   - Else → `addFirst()`
4. Toggle direction after each level.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {

        List<List<Integer>> answer = new ArrayList<>();

        if (root == null)
            return answer;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        boolean leftToRight = true;

        while (!queue.isEmpty()) {

            int size = queue.size();
            LinkedList<Integer> level = new LinkedList<>();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                if (leftToRight)
                    level.addLast(node.val);
                else
                    level.addFirst(node.val);

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            answer.add(level);

            leftToRight = !leftToRight;
        }

        return answer;
    }
}
```

# Approach 3 : DFS (Recursive)

## Idea

DFS can also solve this problem.

Store nodes according to their level.

For each level:

- If even → add at the end.
- If odd → add at the beginning.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {

        List<List<Integer>> answer = new ArrayList<>();

        dfs(root, 0, answer);

        return answer;
    }

    private void dfs(TreeNode node, int level, List<List<Integer>> answer) {

        if (node == null)
            return;

        if (level == answer.size())
            answer.add(new LinkedList<>());

        LinkedList<Integer> current = (LinkedList<Integer>) answer.get(level);

        if (level % 2 == 0)
            current.addLast(node.val);
        else
            current.addFirst(node.val);

        dfs(node.left, level + 1, answer);
        dfs(node.right, level + 1, answer);
    }
}
```

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| BFS + Reverse | O(n) | O(n) |
| BFS + Deque | O(n) | O(n) |
| DFS | O(n) | O(h) |

---

# Why is the Deque approach preferred?

Suppose a level contains

```text
[1,2,3,4,5]
```

Using reverse:

```text
Collect

↓

Reverse entire list
```

Using a deque:

```text
5

↓

4 5

↓

3 4 5

↓

2 3 4 5

↓

1 2 3 4 5
```

No additional reverse operation is needed.

---

# Key Interview Points

- Zigzag traversal is a variation of **Level Order Traversal (LeetCode 102)**.
- A boolean flag is used to alternate the traversal direction after each level.
- The simplest solution is **BFS + Reverse**.
- A more elegant solution uses a **Deque (`LinkedList`)** with `addFirst()` and `addLast()` to avoid reversing.
- DFS is also possible by inserting values at the beginning or end of each level based on the level number.
- All approaches visit each node exactly once, resulting in **O(n)** time complexity.
