# 199. Binary Tree Right Side View

**Difficulty:** Medium

---

# Problem Statement

Given the `root` of a binary tree, imagine yourself standing on the **right side** of it.

Return the values of the nodes that are visible from **top to bottom**.

---

# Example 1

```text
Input:

        1
       / \
      2   3
       \   \
        5   4

Output:

[1,3,4]
```

Explanation

```text
Right Side View

        1  <-

       / \

      2   3  <-

       \   \

        5   4 <-
```

Visible nodes:

```
1 → 3 → 4
```

---

```text

      3

```

---

# Example 3

```text

[]

[]
```

# Approach 1 : BFS (Level Order Traversal)

## Idea

Traverse the tree **level by level**.

For every level,

the **last node** processed is the **rightmost node**.

Store that node in the answer.

---

## Algorithm

1. If root is `null`, return an empty list.
2. Perform Level Order Traversal (BFS).
3. For each level:
   - Process all nodes.
   - The last node of that level is visible from the right.
4. Return the answer.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<Integer> rightSideView(TreeNode root) {

        List<Integer> answer = new ArrayList<>();

        if (root == null)
            return answer;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            int size = queue.size();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);

                if (i == size - 1)
                    answer.add(node.val);
            }
        }

        return answer;
    }
}
```

# Approach 2 : DFS (Right First)

## Idea

Visit the **right child before the left child**.

The first node visited at every depth is the node visible from the right.

---

## Algorithm

1. Traverse recursively.
2. Visit:
   - Root
   - Right
   - Left
3. If visiting a depth for the first time:
   - Add the node to the answer.

---

## Java Code

```java
import java.util.*;

class Solution {

    List<Integer> answer = new ArrayList<>();

    public List<Integer> rightSideView(TreeNode root) {

        dfs(root, 0);

        return answer;
    }

    private void dfs(TreeNode node, int depth) {

        if (node == null)
            return;

        if (depth == answer.size())
            answer.add(node.val);

        dfs(node.right, depth + 1);

        dfs(node.left, depth + 1);
    }
}
```

# Comparison

| Approach | Time | Space |
|----------|------|-------|
| BFS (Level Order) | O(n) | O(n) |
| DFS (Right First) | O(n) | O(h) |

---

# Why does DFS visit the Right child first?

Suppose

```text
        1
       / \
      2   3
```

If we visit

```text
Left first
```

the first node at depth 1 becomes

```
2
```

which is incorrect.

Instead,

visit

```text
Right first
```

The first node at each depth becomes

```
3
```

which is exactly what is visible from the right side.

---

# Key Interview Points

- BFS solution stores the **last node** of every level.
- DFS solution visits **Right → Left**.
- The **first node encountered at each depth** is the answer.
- DFS generally uses less auxiliary memory on balanced trees (`O(h)` recursion stack).
- Both approaches visit every node exactly once, resulting in **O(n)** time complexity.
