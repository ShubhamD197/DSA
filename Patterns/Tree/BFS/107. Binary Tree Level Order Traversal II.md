# 107. Binary Tree Level Order Traversal II

**Difficulty:** Easy

---

# Problem Statement

Given the `root` of a binary tree, return the **bottom-up level order traversal** of its nodes' values.

That is,

- Traverse the tree level by level.
- Return the levels starting from the **lowest level** to the **root**.

---

# Example 1

```text
Input:

        3
       / \
      9   20
         /  \
        15   7

Output:

[[15,7],
 [9,20],
 [3]]
```

---

# Example 2

```text
Input:

    1

Output:

[[1]]
```

---

# Example 3

```text
Input:

[]

Output:

[]
```

---

# Approach 1 : BFS (Level Order Traversal + Reverse)

## Idea

Perform a normal **Level Order Traversal (BFS)**.

This gives the levels from

```text
Top → Bottom
```

Finally,

reverse the result to obtain

```text
Bottom → Top
```

---

## Algorithm

1. If root is `null`, return an empty list.
2. Create a queue and insert the root.
3. While the queue is not empty:
   - Process all nodes of the current level.
   - Store their values in a list.
   - Add their children to the queue.
   - Add the level list to the result.
4. Reverse the result.
5. Return the result.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {

        List<List<Integer>> result = new ArrayList<>();

        if (root == null)
            return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            int size = queue.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                level.add(node.val);

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            result.add(level);
        }

        Collections.reverse(result);

        return result;
    }
}
```

# Approach 2 : BFS (Insert at Front)

## Idea

Instead of reversing at the end,

insert every level at the **front** of the answer.

This automatically builds the answer in bottom-up order.

---

## Algorithm

1. Perform normal BFS.
2. For every completed level:
   - Insert it at index `0`.
3. Return the answer.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {

        LinkedList<List<Integer>> result = new LinkedList<>();

        if (root == null)
            return result;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            int size = queue.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                level.add(node.val);

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            result.addFirst(level);
        }

        return result;
    }
}
```

# Approach 3 : DFS (Recursive)

## Idea

DFS can also solve this problem.

Store nodes according to their level.

After DFS finishes,

reverse the list.

---

## Algorithm

1. DFS with `level`.
2. If the current level does not exist, create a new list.
3. Add the node to its level.
4. Recurse left.
5. Recurse right.
6. Reverse the answer.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> levelOrderBottom(TreeNode root) {

        List<List<Integer>> result = new ArrayList<>();

        dfs(root, 0, result);

        Collections.reverse(result);

        return result;
    }

    private void dfs(TreeNode node, int level, List<List<Integer>> result) {

        if (node == null)
            return;

        if (level == result.size())
            result.add(new ArrayList<>());

        result.get(level).add(node.val);

        dfs(node.left, level + 1, result);
        dfs(node.right, level + 1, result);
    }
}
```

# Key Interview Points

- This problem is almost identical to **Level Order Traversal (LeetCode 102)**.
- The only difference is that the final answer is returned from **bottom to top**.
- BFS is the most common and interview-friendly solution.
- Using a `LinkedList` with `addFirst()` avoids an explicit reverse operation.
- Every node is visited exactly once, giving an **O(n)** time complexity.
