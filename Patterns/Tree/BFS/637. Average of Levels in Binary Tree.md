# 637. Average of Levels in Binary Tree

**Difficulty:** Easy

---

# Problem Statement

Given the `root` of a binary tree, return the **average value of the nodes on each level** as an array.

The answer should contain one average for every level of the tree.

---

# Example 1

```text
Input:

        3
       / \
      9   20
         /  \
        15   7

Output:

[3.00000, 14.50000, 11.00000]
```

Explanation

```text
Level 0

3

Average = 3 / 1 = 3

----------------

Level 1

9 20

Average = (9 + 20) / 2 = 14.5

----------------

Level 2

15 7

Average = (15 + 7) / 2 = 11
```

---

# Example 2

```text

        3

     / \
    15  7

```

# Approach 1 : BFS (Level Order Traversal)

## Idea

Perform a normal **Level Order Traversal**.

For every level:

- Calculate the sum of all nodes.
- Divide the sum by the number of nodes in that level.
- Store the average.

---

## Algorithm

1. If root is null, return an empty list.
2. Insert root into a queue.
3. While queue is not empty:
   - Find the number of nodes in the current level.
   - Calculate the sum of all nodes in that level.
   - Add children into the queue.
   - Average = sum / level size.
4. Return the answer.

---

## Java Code

```java
import java.util.*;

class Solution {
    public List<Double> averageOfLevels(TreeNode root) {

        List<Double> answer = new ArrayList<>();

        if (root == null)
            return answer;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            int size = queue.size();

            long sum = 0;

            for (int i = 0; i < size; i++) {

                TreeNode node = queue.poll();

                sum += node.val;

                if (node.left != null)
                    queue.offer(node.left);

                if (node.right != null)
                    queue.offer(node.right);
            }

            answer.add((double) sum / size);
        }

        return answer;
    }
}
```

---

## Why use `long` instead of `int`?

Suppose one level contains

```text
1000000000

1000000000

1000000000
```

Using `int`

```text
sum = 3000000000
```

This exceeds Java's `int` range and causes **integer overflow**.

Using

```java
long sum
```

prevents overflow.

# Approach 2 : DFS (Recursive)

## Idea

DFS can also solve this problem.

For every level,

store

- Total sum
- Number of nodes

After DFS,

calculate

```text
Average = Sum / Count
```

---

## Algorithm

1. Traverse recursively.
2. If visiting a level for the first time:
   - Create entries for sum and count.
3. Update:
   - Sum
   - Count
4. After traversal,
   calculate the average for every level.

---

## Java Code

```java
import java.util.*;

class Solution {

    List<Long> sums = new ArrayList<>();
    List<Integer> counts = new ArrayList<>();

    public List<Double> averageOfLevels(TreeNode root) {

        dfs(root, 0);

        List<Double> answer = new ArrayList<>();

        for (int i = 0; i < sums.size(); i++) {
            answer.add((double) sums.get(i) / counts.get(i));
        }

        return answer;
    }

    private void dfs(TreeNode node, int level) {

        if (node == null)
            return;

        if (level == sums.size()) {
            sums.add(0L);
            counts.add(0);
        }

        sums.set(level, sums.get(level) + node.val);
        counts.set(level, counts.get(level) + 1);

        dfs(node.left, level + 1);
        dfs(node.right, level + 1);
    }
}
```

# Key Interview Points

- BFS is the most common solution because it naturally processes one level at a time.
- Use a **`long`** variable to store the sum and avoid integer overflow.
- Average is calculated as `(double) sum / size`.
- DFS can also solve the problem by maintaining separate **sum** and **count** for each level.
- Every node is visited exactly once, resulting in **O(n)** time complexity.
