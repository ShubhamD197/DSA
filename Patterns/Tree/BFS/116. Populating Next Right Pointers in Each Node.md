# 116. Populating Next Right Pointers in Each Node

**Difficulty:** Medium

---

# Problem Statement

You are given a **perfect binary tree**, where:

- Every parent has exactly **two children**.
- All leaf nodes are at the **same level**.

Populate each `next` pointer so that it points to its **next right node**.

If there is no next right node, the `next` pointer should be set to `NULL`.

Initially, all `next` pointers are `NULL`.

---

# Example

```text
Input

          1
        /   \
       2     3
      / \   / \
     4   5 6   7

Output

          1 -> NULL

        /          \

       2 -------> 3 -> NULL

      / \        / \

     4->5->6->7->NULL
```

Return the root after connecting all `next` pointers.

---

# Approach 1 : BFS (Level Order Traversal)

## Idea

Perform a normal **Level Order Traversal**.

For every level,

connect each node to the next node in the queue.

The last node of every level points to `NULL`.

---

## Algorithm

1. If root is null, return null.
2. Insert root into a queue.
3. While queue is not empty:
   - Process one level.
   - Connect each node with the next node.
   - Insert left and right children.
4. Return root.

---

## Java Code

```java
import java.util.*;

class Solution {
    public Node connect(Node root) {

        if (root == null)
            return null;

        Queue<Node> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {

            int size = queue.size();

            Node previous = null;

            for (int i = 0; i < size; i++) {

                Node current = queue.poll();

                if (previous != null)
                    previous.next = current;

                previous = current;

                if (current.left != null)
                    queue.offer(current.left);

                if (current.right != null)
                    queue.offer(current.right);
            }
        }

        return root;
    }
}
```

# Approach 2 : Optimal (Using Existing Next Pointers)

## Idea

Since the tree is **perfect**, every node has:

- Left child
- Right child

Use the already established `next` pointers to connect the next level.

For every node:

### Rule 1

Connect

```text
node.left

↓

node.right
```

---

### Rule 2

If

```text
node.next != null
```

then

```text
node.right

↓

node.next.left
```

This connects nodes across different parents.

---

## Algorithm

1. Start from the root.
2. Traverse one level using `next` pointers.
3. For each node:
   - Connect left → right.
   - Connect right → next.left (if exists).
4. Move to the leftmost node of the next level.
5. Repeat until reaching the leaf level.

## Java Code

```java
class Solution {
    public Node connect(Node root) {

        if (root == null)
            return null;

        Node leftMost = root;

        while (leftMost.left != null) {

            Node current = leftMost;

            while (current != null) {

                // Connect left child to right child
                current.left.next = current.right;

                // Connect right child to next subtree
                if (current.next != null)
                    current.right.next = current.next.left;

                current = current.next;
            }

            leftMost = leftMost.left;
        }

        return root;
    }
}
```

---

## Why does this work?

Because the tree is **perfect**.

Every parent has:

```text
left child

right child
```

So we can always safely connect

```text
left → right
```

Also,

if a parent has a next node,

its right child should connect to that next node's left child.

Example

```text
      2 -----> 3

     / \      / \

    4   5    6   7
```

Connections

```text
4 -> 5

5 -> 6

6 -> 7
```

No queue is required.

---

## Complexity

- Time : **O(n)**
- Space : **O(1)**

(No extra queue or recursion stack.)

---

# Why is the Optimal Approach possible only for a Perfect Binary Tree?

Because every node is guaranteed to have:

- A left child.
- A right child.

This guarantees that:

```text
node.left.next = node.right
```

is always valid.

Also, if `node.next` exists, then:

```text
node.right.next = node.next.left
```

is also always valid.

For a general binary tree, these assumptions are not true, so this approach cannot be used.

---

# Key Interview Points

- A **perfect binary tree** has all internal nodes with exactly two children, and all leaves are at the same level.
- BFS is the straightforward solution using a queue.
- The optimal solution uses already established `next` pointers to traverse each level.
- Connect:
  - `left → right`
  - `right → next.left`
- The optimal approach achieves **O(n)** time and **O(1)** extra space.
