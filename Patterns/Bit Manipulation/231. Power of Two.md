# LeetCode 231 — Power of Two

## Problem

Check whether a number is a power of 2.

Examples:

```text id="1e23pq"
1  → true   (2^0)
2  → true   (2^1)
4  → true   (2^2)
8  → true   (2^3)
3  → false
5  → false
```

---

# Key Observation

Power of 2 numbers have only **one set bit**.

Binary:

```text id="7v8mcd"
1  = 0001
2  = 0010
4  = 0100
8  = 1000
```

---

# Trick

For any power of 2:

```text id="lw0v8t"
n & (n - 1) = 0
```

Example:

```text id="7w9c9k"
8      = 1000
8 - 1  = 0111

1000 & 0111 = 0000
```

---

# Code

```java id="wmdh8w"
class Solution {

    public boolean isPowerOfTwo(int n) {

        // n must be positive
        if (n <= 0) {
            return false;
        }

        return (n & (n - 1)) == 0;
    }
}
```
