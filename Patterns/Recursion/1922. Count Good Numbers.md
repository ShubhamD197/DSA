# 1922. Count Good Numbers

**Difficulty:** Medium

**Topic:** Recursion / Fast Exponentiation / Modular Arithmetic

---

# Problem Statement

A digit string is called **good** if:

- Digits at **even indices** (`0, 2, 4, ...`) are even digits: `0, 2, 4, 6, 8`.
- Digits at **odd indices** (`1, 3, 5, ...`) are prime digits: `2, 3, 5, 7`.

Given an integer `n`, return the total number of good digit strings of length `n`.

Since the answer can be very large, return the result modulo:

```text
10^9 + 7
```

```text
Answer = 5
```

For `n` digits:

Number of even indices:

```text

```

Number of odd indices:

```text

```

Therefore:


```java

```

We need **Binary Exponentiation**.

# Approach 1: Simple Recursion

## Idea

We can recursively calculate the answer by processing one position at a time.

For every position:

- Even index → `5` choices
- Odd index → `4` choices

So:

```text
f(n) = choices × f(n - 1)
```

---

## Java Code

```java
class Solution {

    private static final long MOD = 1_000_000_007;

    public int countGoodNumbers(long n) {

        return (int) solve(n);
    }

    private long solve(long n) {

        // No positions left
        if (n == 0) {
            return 1;
        }

        // Position n - 1
        if ((n - 1) % 2 == 0) {

            // Even index -> 5 choices
            return (5 * solve(n - 1)) % MOD;

        } else {

            // Odd index -> 4 choices
            return (4 * solve(n - 1)) % MOD;
        }
    }
}
```

# Approach 2: Iterative Power Calculation

## Idea

We know:

```text
Answer = 5^((n+1)/2) × 4^(n/2)
```

We can calculate powers using a loop.

However, calculating:

```text
5^power
```

one multiplication at a time takes:

```text
O(power)
```

which is still too slow for:

```text
n = 10^15
```

So this approach is also not suitable for the constraints.

---

## Java Code

```java
class Solution {

    private static final long MOD = 1_000_000_007;

    public int countGoodNumbers(long n) {

        long evenPositions = (n + 1) / 2;
        long oddPositions = n / 2;

        long result = 1;

        for (long i = 0; i < evenPositions; i++) {
            result = (result * 5) % MOD;
        }

        for (long i = 0; i < oddPositions; i++) {
            result = (result * 4) % MOD;
        }

        return (int) result;
    }
}
```

# Approach 3: Binary Exponentiation

## Idea

We need to calculate:

```text
5^((n+1)/2)
```

and:

```text
4^(n/2)
```

efficiently.

Binary exponentiation calculates:

```text
a^b
```

in:

```text
O(log b)
```

instead of:

```text
O(b)
```

The main idea is to repeatedly square the base.

For example:

```text
a^8
```

can be calculated as:

```text
a^8
= (a^4)^2
= ((a^2)^2)^2
```

So instead of multiplying `a` eight times, we use only a few operations.

---

## Java Code

```java
class Solution {

    private static final long MOD = 1_000_000_007;

    public int countGoodNumbers(long n) {

        long evenPositions = (n + 1) / 2;
        long oddPositions = n / 2;

        long evenWays = power(5, evenPositions);
        long oddWays = power(4, oddPositions);

        return (int) ((evenWays * oddWays) % MOD);
    }

    private long power(long base, long exponent) {

        long result = 1;

        while (exponent > 0) {

            // If exponent is odd,
            // multiply the current result by base
            if ((exponent & 1) == 1) {
                result = (result * base) % MOD;
            }

            // Square the base
            base = (base * base) % MOD;

            // Divide exponent by 2
            exponent >>= 1;
        }

        return result;
    }
}
```

# Approach 4: Recursive Fast Power

## Idea

Binary exponentiation can also be implemented recursively.

The main mathematical idea is:

If `n` is even:

```text
a^n = a^(n/2) × a^(n/2)
```

If `n` is odd:

```text
a^n = a × a^(n-1)
```

A better way to write the odd case is:

```text
a^n = a × (a^(n/2)) × (a^(n/2))
```

So we calculate:

```text
half = power(a, n / 2)
```

only once.

---

## Java Code

```java
class Solution {

    private static final long MOD = 1_000_000_007;

    public int countGoodNumbers(long n) {

        long evenPositions = (n + 1) / 2;
        long oddPositions = n / 2;

        long evenWays = power(5, evenPositions);
        long oddWays = power(4, oddPositions);

        return (int) ((evenWays * oddWays) % MOD);
    }

    private long power(long base, long exponent) {

        if (exponent == 0) {
            return 1;
        }

        long half = power(base, exponent / 2);

        long result = (half * half) % MOD;

        if (exponent % 2 == 1) {
            result = (result * base) % MOD;
        }

        return result;
    }
}
```

The exponent was reduced from:


```text

```

For very large values, this difference becomes significant.

# Which Approach Is Better?

## Best Overall: Iterative Binary Exponentiation

The iterative binary exponentiation approach is the best solution.

It has:

```text
Time: O(log n)
Space: O(1)
```

This is ideal because:

```text
n <= 10^15
```

We cannot iterate `n` times.

Instead, binary exponentiation reduces the exponent by half in every iteration:

```text
n
n/2
n/4
n/8
...
```

Therefore, only:

```text
O(log n)
```

iterations are needed.

# Why Do We Use Modulo?

The answer can become extremely large.

For example:

```text
5^500000000000000
```

cannot fit inside a normal Java `int` or `long`.

The problem asks us to return:

```text
answer % (10^9 + 7)
```

So we use:

```java
private static final long MOD = 1_000_000_007;
```

and apply modulo during multiplication:

```java
result = (result * base) % MOD;
```

This keeps the values manageable.

---

# Why Do We Use `long`?

Even though the final answer is returned as an `int`, intermediate multiplication can exceed the range of an `int`.

For example:

```java
result * base
```

can be larger than:

```text
2^31 - 1
```

Therefore, we use:

```java
long
```

for calculations.

At the end:

```java
return (int) ((evenWays * oddWays) % MOD);
```
