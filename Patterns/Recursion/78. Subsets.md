# 78. Subsets

**Difficulty:** Medium

**Topic:** Backtracking / Recursion / Bit Manipulation

---

# Problem Statement

Given an integer array `nums` of **unique elements**, return all possible subsets (the power set).

The solution set must not contain duplicate subsets.

You may return the answer in any order.

---

```text
Input

Output

[

    [1],
    [2],
    [3],
    [1,2],
    [1,3],
    [2,3],
    [1,2,3]
]
```

---

# Example 2

```text
Input

nums = [0]

Output

[
    [],
    [0]
]
```

# Understanding the Problem

For every element, we have exactly **two choices**:

```text
Take the element

OR

Don't take the element
```

For

```text
nums = [1,2,3]
```

The decision tree looks like:

```text
                         []
                       /    \
                    Take    Skip
                     1        1
                    /          \
                 [1]            []
                /   \          /  \
              Take Skip     Take Skip
               2     2        2     2
              /       \      /       \
           [1,2]      [1]   [2]       []
             ...
```

Each element creates **2 choices**.

Therefore, the total number of subsets is:

```text
2ⁿ
```

---

# Number of Subsets

For an array of size `n`:

```text
Number of subsets = 2ⁿ
```

Examples:

```text
n = 0 → 1 subset

n = 1 → 2 subsets

n = 2 → 4 subsets

n = 3 → 8 subsets

n = 4 → 16 subsets
```

The empty subset is always included.

---

# Approach 1 : Brute Force Recursion (Take / Not Take)

## Idea

At every index, we have two choices:

```text
Take nums[index]

OR

Skip nums[index]
```

When we reach the end, add the current subset to the answer.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsets(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        solve(nums, 0, new ArrayList<>(), answer);

        return answer;
    }

    private void solve(int[] nums,
                       int index,
                       List<Integer> current,
                       List<List<Integer>> answer) {

        if (index == nums.length) {

            answer.add(new ArrayList<>(current));

            return;
        }

        // Take the current element
        current.add(nums[index]);

        solve(nums, index + 1, current, answer);

        // Backtrack
        current.remove(current.size() - 1);

        // Skip the current element
        solve(nums, index + 1, current, answer);
    }
}
```

# Important Backtracking Step

After taking an element:

```java
current.add(nums[index]);
```

we recursively explore.

Then we remove it:

```java
current.remove(current.size() - 1);
```

This is called **backtracking**.

It allows us to explore the branch where the element is not selected.


- Time : **O(n × 2ⁿ)**

- Output Space : **O(n × 2ⁿ)**

# Approach 2 : Backtracking with For Loop

## Idea

Instead of explicitly writing:

```text
Take

Skip
```

we can use a `for` loop.

At every recursion level:

1. Add the current subset to the answer.
2. Try every possible next element.
3. Backtrack.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsets(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        backtrack(nums, 0, new ArrayList<>(), answer);

        return answer;
    }

    private void backtrack(int[] nums,
                           int start,
                           List<Integer> current,
                           List<List<Integer>> answer) {

        // Every current state is a valid subset
        answer.add(new ArrayList<>(current));

        for (int i = start; i < nums.length; i++) {

            // Choose
            current.add(nums[i]);

            // Explore
            backtrack(nums, i + 1, current, answer);

            // Undo choice
            current.remove(current.size() - 1);
        }
    }
}
```

# Approach 3 : Iterative Approach

## Idea

Start with the empty subset.

For every number:

1. Take all existing subsets.
2. Create a copy of each subset.
3. Add the current number to the copy.
4. Add the new subsets to the result.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsets(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        answer.add(new ArrayList<>());

        for (int num : nums) {

            int size = answer.size();

            for (int i = 0; i < size; i++) {

                List<Integer> newSubset =
                        new ArrayList<>(answer.get(i));

                newSubset.add(num);

                answer.add(newSubset);
            }
        }

        return answer;
    }
}
```

# Approach 4 : Bit Manipulation

## Key Idea

Every subset can be represented by a binary number.

For `n` elements, we have:

```text
2ⁿ
```

possible binary masks.

For

```text
nums = [1,2,3]
```

we have

```text
000
001
010
011
100
101
110
111
```

Each bit represents whether an element is selected.

```text
Bit = 1 → Include

Bit = 0 → Exclude
```

---

# Bitmask Representation

```text
nums = [1,2,3]
        ↑ ↑ ↑
       bit2 bit1 bit0
```

Example

```text
101
```

Means:

```text
1 → Include

2 → Exclude

3 → Include
```

Subset:

```text
[1,3]
```

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsets(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        int n = nums.length;

        int total = 1 << n;

        for (int mask = 0; mask < total; mask++) {

            List<Integer> subset = new ArrayList<>();

            for (int i = 0; i < n; i++) {

                if ((mask & (1 << i)) != 0) {

                    subset.add(nums[i]);
                }
            }

            answer.add(subset);
        }

        return answer;
    }
}
```

# Bit Manipulation Explanation

The expression

```java
(1 << i)
```

creates a number where only the `i-th` bit is `1`.

Example:

```text
i = 0

1 << 0

=

001
```

```text
i = 1

1 << 1

=

010
```

```text
i = 2

1 << 2

=

100
```

Then:

```java
mask & (1 << i)
```

checks whether the `i-th` bit is set.

If the result is not zero:

```text
Element is included.
```

# DP / Recursion Pattern

For Take / Not Take:

```text
                       []
                     /    \
                  Take    Skip
                   1        1
                  /          \
               [1]            []
              /   \          /  \
           Take Skip      Take Skip
             2     2        2     2
```

The general pattern is:

```java
current.add(nums[index]);

solve(index + 1);

current.remove(current.size() - 1);

solve(index + 1);
```

---

# Backtracking Pattern

The general template is:

```java
void backtrack(start) {

    answer.add(current);

    for (int i = start; i < n; i++) {

        // Choose
        current.add(nums[i]);

        // Explore
        backtrack(i + 1);

        // Undo
        current.remove(current.size() - 1);
    }
}
```

This pattern is extremely important for:

- Subsets
- Subsets II
- Combinations
- Combination Sum
- Combination Sum II
- Permutations
- Permutations II

# Key Interview Points

- Every element has exactly **two choices**: take or skip.
- An array of size `n` has exactly **2ⁿ subsets**.
- The empty subset `[]` is always included.
- The **Take / Not Take** approach is useful for understanding recursion.
- The **Backtracking with a for-loop** approach is the standard pattern for subset-generation problems.
- The **Bit Manipulation** approach represents each subset using a binary mask.
- Time Complexity: **O(n × 2ⁿ)** because there are `2ⁿ` subsets and copying each subset can take up to `O(n)`.
- Output Space: **O(n × 2ⁿ)**.
