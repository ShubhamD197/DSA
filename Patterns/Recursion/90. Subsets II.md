# 90. Subsets II

**Difficulty:** Medium

**Topic:** Backtracking / Recursion / Sorting

---

## Problem Statement

Given an integer array `nums` that may contain **duplicates**, return all possible subsets (the power set).

The solution set must **not contain duplicate subsets**.

You may return the answer in any order.

```text
]
```

# Understanding the Problem

The main difference between **LeetCode 78 - Subsets** and **LeetCode 90 - Subsets II** is that the input array can contain duplicate elements.

For example:

```text
nums = [1,2,2]
```

If we generate subsets normally, we can get duplicate subsets:

```text
[2]  <- using first 2

[2]  <- using second 2
```

We need to make sure that the final answer contains only unique subsets.

The main technique is:

```text
1. Sort the array.
2. Use backtracking.
3. Skip duplicate elements at the same recursion level.
```

---

# Why Do We Sort the Array?

Consider:

```text
nums = [2,1,2]
```

After sorting:

```text
nums = [1,2,2]
```

Now duplicate elements are adjacent:

```text
1  2  2
   ↑  ↑
   duplicate
```

This allows us to easily detect duplicates using:

```java
nums[i] == nums[i - 1]
```

---

# Key Duplicate Condition

The most important line in this problem is:

```java
if (i > start && nums[i] == nums[i - 1]) {
    continue;
}
```

This means:

> If the current element is the same as the previous element at the same recursion level, skip it.

---

# Why `i > start`?

This is very important.

Consider:

```text
nums = [2,2]
```

At the root level:

```text
[]
```

We have two identical choices:

```text
[]
├── 2
└── 2  <- Skip this
```

The second `2` is skipped because choosing it would generate the same subsets as choosing the first `2`.

However, after choosing the first `2`:

```text
[2]
```

we are allowed to choose the second `2`:

```text
[2,2]
```

Therefore:

```text
Same recursion level
→ Skip duplicate

Different recursion level
→ Allow duplicate
```

This is why we use:

```java
i > start
```

instead of:

```java
i > 0
```

# Approach 1: Backtracking

## Idea

At every recursion level:

1. Add the current subset to the answer.
2. Try every possible element from `start`.
3. Skip duplicate elements at the same recursion level.
4. Add the selected element.
5. Recursively generate subsets.
6. Remove the element using backtracking.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsetsWithDup(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        // Sort to bring duplicates together
        Arrays.sort(nums);

        backtrack(nums, 0, new ArrayList<>(), answer);

        return answer;
    }

    private void backtrack(
            int[] nums,
            int start,
            List<Integer> current,
            List<List<Integer>> answer) {

        // Every current state is a valid subset
        answer.add(new ArrayList<>(current));

        for (int i = start; i < nums.length; i++) {

            // Skip duplicates at the same recursion level
            if (i > start && nums[i] == nums[i - 1]) {
                continue;
            }

            // Choose
            current.add(nums[i]);

            // Explore
            backtrack(
                nums,
                i + 1,
                current,
                answer
            );

            // Undo choice
            current.remove(current.size() - 1);
        }
    }
}
```

# Approach 2: Take / Not Take Recursion

Another way to solve the problem is using the **Take / Not Take** pattern.

For every element, we have two choices:

```text
Take

OR

Don't Take
```

The duplicate handling is slightly different.

When we decide **not to take** an element, we skip all consecutive duplicates.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsetsWithDup(int[] nums) {

        List<List<Integer>> answer = new ArrayList<>();

        Arrays.sort(nums);

        solve(
            nums,
            0,
            new ArrayList<>(),
            answer
        );

        return answer;
    }

    private void solve(
            int[] nums,
            int index,
            List<Integer> current,
            List<List<Integer>> answer) {

        if (index == nums.length) {

            answer.add(new ArrayList<>(current));

            return;
        }

        // Take current element
        current.add(nums[index]);

        solve(
            nums,
            index + 1,
            current,
            answer
        );

        // Backtrack
        current.remove(current.size() - 1);

        // Skip all duplicates
        int nextIndex = index + 1;

        while (
            nextIndex < nums.length &&
            nums[nextIndex] == nums[index]
        ) {
            nextIndex++;
        }

        // Don't take current element
        solve(
            nums,
            nextIndex,
            current,
            answer
        );
    }
}
```

# Approach 3: Iterative

## Idea

For normal subsets, we can do:

```text
For every number:

    Add the number to every existing subset.
```

For duplicates, we need to make sure that a duplicate number only extends the subsets created during the previous iteration.

---

## Example

```text
nums = [1,2,2]
```

Start:

```text
[
    []
]
```

After `1`:

```text
[
    [],
    [1]
]
```

After first `2`:

```text
[
    [],
    [1],
    [2],
    [1,2]
]
```

When processing the second `2`, we only extend the subsets created by the previous `2`:

```text
[2]
[1,2]
```

New subsets:

```text
[2,2]
[1,2,2]
```

Final:

```text
[
    [],
    [1],
    [2],
    [1,2],
    [2,2],
    [1,2,2]
]
```

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsetsWithDup(int[] nums) {

        Arrays.sort(nums);

        List<List<Integer>> answer = new ArrayList<>();

        answer.add(new ArrayList<>());

        int start = 0;

        for (int i = 0; i < nums.length; i++) {

            int previousSize = answer.size();

            if (i > 0 && nums[i] == nums[i - 1]) {

                // Only extend subsets created
                // during the previous iteration
                start = start;

            } else {

                // New number can extend all subsets
                start = 0;
            }

            for (int j = start; j < previousSize; j++) {

                List<Integer> subset =
                        new ArrayList<>(answer.get(j));

                subset.add(nums[i]);

                answer.add(subset);
            }

            start = previousSize;
        }

        return answer;
    }
}
```

---

# Complexity

* Time: `O(n * 2^n)`
* Space: `O(n * 2^n)`

The output itself requires `O(n * 2^n)` space in the worst case.

# Approach 4: Bit Manipulation + Set

A direct bitmask solution works perfectly for **LeetCode 78** because all input elements are unique.

For LeetCode 90, duplicate values can produce duplicate subsets.

Example:

```text
nums = [1,2,2]
```

Different masks can produce the same subset:

```text
001 → [1]

010 → [2]

100 → [2]
```

We can use a `Set` to remove duplicate subsets.

---

## Java Code

```java
import java.util.*;

class Solution {

    public List<List<Integer>> subsetsWithDup(int[] nums) {

        Set<List<Integer>> set = new HashSet<>();

        int n = nums.length;

        for (int mask = 0; mask < (1 << n); mask++) {

            List<Integer> subset = new ArrayList<>();

            for (int i = 0; i < n; i++) {

                if ((mask & (1 << i)) != 0) {

                    subset.add(nums[i]);
                }
            }

            set.add(subset);
        }

        return new ArrayList<>(set);
    }
}
```

---

# Complexity

There are:

```text
2^n
```

possible masks.

For every mask, we check `n` elements.

Therefore:

```text
Time = O(n * 2^n)

Space = O(n * 2^n)
```

This approach is generally not preferred because it generates duplicate subsets first and removes them afterward.

# Why `i > start` Is Important

Consider:

```text
nums = [2,2]
```

At the root:

```text
[]
```

Choose the first `2`:

```text
[2]
```

Then choose the second `2`:


This must be allowed.

If we used:


That would cause us to miss:


# Backtracking Template

This is the main template you should remember:

```java
void backtrack(int start) {

    // Current state is always a valid subset
    answer.add(new ArrayList<>(current));

    for (int i = start; i < nums.length; i++) {

        // Skip duplicate choices at the same level
        if (i > start && nums[i] == nums[i - 1]) {
            continue;
        }

        // Choose
        current.add(nums[i]);

        // Explore
        backtrack(i + 1);

        // Undo
        current.remove(current.size() - 1);
    }
}
```

# Key Interview Points

* LeetCode 90 is the duplicate version of **LeetCode 78**.
* Sort the array first so duplicate elements become adjacent.
* Use:

```java
if (i > start && nums[i] == nums[i - 1]) {
    continue;
}
```

* This skips duplicate choices at the **same recursion level**.
* Do not skip duplicates at different recursion levels because `[2,2]` is a valid subset.
* The empty subset is always included.
* The **Backtracking** solution is the preferred interview solution.
* Time Complexity: `O(n log n + n * 2^n)`, effectively `O(n * 2^n)`.
* Auxiliary Space: `O(n)`, excluding the output.
* Output Space: `O(n * 2^n)` in the worst case.
