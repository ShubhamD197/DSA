# 1092. Shortest Common Supersequence

**Difficulty:** Hard

**Topic:** Dynamic Programming (LCS Based)

---

# Problem Statement

Given two strings `str1` and `str2`, return the **Shortest Common Supersequence (SCS)**.

A **Supersequence** of a string is a string that contains the original string as a subsequence.

The returned string should contain **both** `str1` and `str2` as subsequences while having the **minimum possible length**.

If multiple answers exist, return any one of them.

---

Length = 5

# Key Observation

Suppose

```text
str1 = abcde

str2 = ace
```

The common characters

```text
a c e
```

should appear **only once** in the final answer.

Everything else must be included.

Therefore,

the **Longest Common Subsequence (LCS)** helps us avoid duplicate characters.

---

# Relationship with LCS

Formula

```text
Length of SCS

=

Length(str1)

+

Length(str2)

-

Length(LCS)
```

Example

```text
str1 = abcde

Length = 5

----------------

str2 = ace

Length = 3

----------------

LCS = ace

Length = 3

----------------

SCS Length

=

5 + 3 - 3

=

5
```

# Idea

1. Find the LCS DP table.
2. Traverse backward from the last cell.
3. Build the shortest supersequence.
4. Reverse the answer.

---

# Why Do We Need the DP Table?

The DP table tells us

```text
Which direction

↑

or

←

belongs to the LCS.
```

Using it, we know

- which character is common
- which character should be added
- when to move diagonally

---

# Approach : Dynamic Programming (LCS + Reconstruction)

---

## Step 1 : Build the LCS DP Table

State

```text
dp[i][j]
```

=

Length of LCS between

```text
str1[0...i-1]

and

str2[0...j-1]
```

Transition

If characters match

```text
dp[i][j]

=

1 + dp[i-1][j-1]
```

Otherwise

```text
max(

dp[i-1][j],

dp[i][j-1]

)
```

---

## Step 2 : Build the Supersequence

Start from

```text
(i,j)

=

(n,m)
```

### Case 1

Characters match

```text
Take character once

Move diagonally
```

---

### Case 2

Top cell larger

```text
Take str1 character

Move up
```

---

### Case 3

Left cell larger

```text
Take str2 character

Move left
```

---

### Finally

If one string remains,

append all remaining characters.

Reverse the answer.

---

# Java Code

```java
class Solution {

    public String shortestCommonSupersequence(String str1, String str2) {

        int n = str1.length();
        int m = str2.length();

        int[][] dp = new int[n + 1][m + 1];

        // Build LCS table
        for (int i = 1; i <= n; i++) {

            for (int j = 1; j <= m; j++) {

                if (str1.charAt(i - 1) == str2.charAt(j - 1)) {

                    dp[i][j] = 1 + dp[i - 1][j - 1];

                } else {

                    dp[i][j] = Math.max(
                            dp[i - 1][j],
                            dp[i][j - 1]
                    );
                }
            }
        }

        StringBuilder answer = new StringBuilder();

        int i = n;
        int j = m;

        while (i > 0 && j > 0) {

            if (str1.charAt(i - 1) == str2.charAt(j - 1)) {

                answer.append(str1.charAt(i - 1));
                i--;
                j--;

            } else if (dp[i - 1][j] > dp[i][j - 1]) {

                answer.append(str1.charAt(i - 1));
                i--;

            } else {

                answer.append(str2.charAt(j - 1));
                j--;
            }
        }

        while (i > 0) {
            answer.append(str1.charAt(i - 1));
            i--;
        }

        while (j > 0) {
            answer.append(str2.charAt(j - 1));
            j--;
        }

        return answer.reverse().toString();
    }
}
```

# Can We Space Optimize?

### Computing only the Length?

Yes.

The LCS length can be computed using two rows.

Space

```text
O(m)
```

---

### Returning the Actual SCS?

No.

To reconstruct the shortest common supersequence, we need to know the path taken in the DP table.

Therefore, the full DP table is required.

# DP Pattern Learned

This problem is an **LCS Reconstruction** problem.

State

```text
dp[i][j]

↓

Length of LCS
```

Transition

```text
Match

↓

Diagonal

----------------

No Match

↓

Move toward larger DP value

----------------

Build answer while moving

↓

Reverse answer
```

# Common Interview Mistakes

### Mistake 1

Appending both matching characters.

Wrong

```text
if same

append both
```

Correct

```text
append only once
```

---

### Mistake 2

Forgetting to append remaining characters after one string finishes.

Always process

```text
while(i>0)

while(j>0)
```

---

### Mistake 3

Forgetting to reverse the answer.

Since we build the string from the end toward the beginning, the result must be reversed before returning.

---

# Key Interview Points

- The Shortest Common Supersequence is built using the **LCS DP table**.
- Common characters are included **only once**.
- Build the standard **LCS DP table**, then reconstruct the answer by traversing backward.
- When characters match, move diagonally and append the character once.
- When they differ, move toward the larger DP value and append the corresponding character.
- Append any remaining characters after one string is exhausted.
- Reverse the constructed string before returning it.
- Time Complexity: **O(n × m)**
- Space Complexity: **O(n × m)**
