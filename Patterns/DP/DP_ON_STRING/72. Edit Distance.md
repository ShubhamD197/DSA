# 72. Edit Distance

**Difficulty:** Medium

**Topic:** Dynamic Programming (String DP)

---

# Problem Statement

Given two strings `word1` and `word2`, return the **minimum number of operations** required to convert `word1` into `word2`.

You are allowed to perform only these three operations:

1. Insert a character
2. Delete a character
3. Replace a character

---

# Example 1

```text
Input

word1 = "horse"

word2 = "ros"

Output

3
```

Explanation

```text
horse

↓

rorse      (Replace 'h' → 'r')

↓

rose       (Delete 'r')

↓

ros        (Delete 'e')
```

Minimum Operations = **3**

---

# Example 2

```text
Input

word1 = "intention"

word2 = "execution"

Output

5
```

Explanation

One possible sequence is

```text
intention

↓

inention     (Delete 't')

↓

enention     (Replace 'i' → 'e')

↓

exention     (Replace 'n' → 'x')

↓

exection     (Replace 'n' → 'c')

↓

execution    (Insert 'u')
```

Minimum Operations = **5**

# Understanding the Problem

We compare both strings character by character.

If the current characters are the same, no operation is required.

Otherwise, we have **three choices**:

- Insert
- Delete
- Replace

We choose the operation that gives the minimum cost.

---

# DP State

Let

```text
solve(i, j)
```

represent:

> Minimum operations required to convert

```text
word1[i...]

into

word2[j...]
```

---

# Choices

Suppose

```text
word1 = horse

word2 = ros
```

Current characters

```text
h

r
```

Different.

We can perform:

### 1. Insert

Insert the current character of `word2` into `word1`.

```text
horse

↓

rhorse
```

Now the inserted character matches `word2[j]`.

Move only in `word2`.

```text
1 + solve(i, j + 1)
```

---

### 2. Delete

Delete the current character from `word1`.

```text
horse

↓

orse
```

Move only in `word1`.

```text
1 + solve(i + 1, j)
```

---

### 3. Replace

Replace the current character.

```text
horse

↓

rorse
```

Both characters are now matched.

Move in both strings.

```text
1 + solve(i + 1, j + 1)
```

---

# Recurrence

If characters match

```text
solve(i, j)

=

solve(i + 1, j + 1)
```

Else

```text
solve(i, j)

=

1 +

min(

Insert,

Delete,

Replace

)
```

or

```text
solve(i, j)

=

1 +

min(

solve(i, j + 1),

solve(i + 1, j),

solve(i + 1, j + 1)

)
```

---

# Base Cases

### Case 1

`word1` is finished.

Only option:

Insert all remaining characters of `word2`.

```text
return word2.length() - j;
```

---

### Case 2

`word2` is finished.

Delete all remaining characters of `word1`.

```text
return word1.length() - i;
```

---

# Approach 1 : Brute Force Recursion

## Java Code

```java
class Solution {

    public int minDistance(String word1, String word2) {
        return solve(word1, word2, 0, 0);
    }

    private int solve(String s1, String s2, int i, int j) {

        if (i == s1.length())
            return s2.length() - j;

        if (j == s2.length())
            return s1.length() - i;

        if (s1.charAt(i) == s2.charAt(j))
            return solve(s1, s2, i + 1, j + 1);

        int insert = solve(s1, s2, i, j + 1);

        int delete = solve(s1, s2, i + 1, j);

        int replace = solve(s1, s2, i + 1, j + 1);

        return 1 + Math.min(insert,
                Math.min(delete, replace));
    }
}
```

# Approach 2 : Memoization (Top-Down DP)

## Idea

The state

```text
(i, j)
```

is computed multiple times.

Store the answer.

---

## DP State

```text
dp[i][j]
```

=

Minimum operations to convert

```text
word1[i...]

↓

word2[j...]
```

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int minDistance(String word1, String word2) {

        int[][] dp = new int[word1.length()][word2.length()];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        return solve(word1, word2, 0, 0, dp);
    }

    private int solve(String s1, String s2,
                      int i, int j,
                      int[][] dp) {

        if (i == s1.length())
            return s2.length() - j;

        if (j == s2.length())
            return s1.length() - i;

        if (dp[i][j] != -1)
            return dp[i][j];

        if (s1.charAt(i) == s2.charAt(j)) {

            return dp[i][j] =
                    solve(s1, s2, i + 1, j + 1, dp);
        }

        int insert = solve(s1, s2, i, j + 1, dp);

        int delete = solve(s1, s2, i + 1, j, dp);

        int replace = solve(s1, s2, i + 1, j + 1, dp);

        return dp[i][j] =
                1 + Math.min(insert,
                        Math.min(delete, replace));
    }
}
```

---

# Complexity

- Time : **O(m × n)**
- Space :
  - DP Table : **O(m × n)**
  - Recursion Stack : **O(m + n)**

# Approach 3 : Tabulation (Bottom-Up)

## DP State

```text
dp[i][j]
```

=

Minimum operations required to convert

```text
word1[i...]

↓

word2[j...]
```

---

## Initialization

If `word1` is exhausted,

```text
dp[m][j] = n - j
```

If `word2` is exhausted,

```text
dp[i][n] = m - i
```

---

## Java Code

```java
class Solution {

    public int minDistance(String word1, String word2) {

        int m = word1.length();
        int n = word2.length();

        int[][] dp = new int[m + 1][n + 1];

        for (int i = 0; i <= m; i++)
            dp[i][n] = m - i;

        for (int j = 0; j <= n; j++)
            dp[m][j] = n - j;

        for (int i = m - 1; i >= 0; i--) {

            for (int j = n - 1; j >= 0; j--) {

                if (word1.charAt(i) == word2.charAt(j)) {

                    dp[i][j] = dp[i + 1][j + 1];

                } else {

                    int insert = dp[i][j + 1];
                    int delete = dp[i + 1][j];
                    int replace = dp[i + 1][j + 1];

                    dp[i][j] = 1 + Math.min(insert,
                                    Math.min(delete, replace));
                }
            }
        }

        return dp[0][0];
    }
}
```

# Approach 4 : Space Optimization

## Observation

Each row depends only on:

- Current row
- Next row

Hence, two 1D arrays are sufficient.

---

## Java Code

```java
class Solution {

    public int minDistance(String word1, String word2) {

        int m = word1.length();
        int n = word2.length();

        int[] next = new int[n + 1];

        for (int j = 0; j <= n; j++) {
            next[j] = n - j;
        }

        for (int i = m - 1; i >= 0; i--) {

            int[] current = new int[n + 1];
            current[n] = m - i;

            for (int j = n - 1; j >= 0; j--) {

                if (word1.charAt(i) == word2.charAt(j)) {

                    current[j] = next[j + 1];

                } else {

                    int insert = current[j + 1];
                    int delete = next[j];
                    int replace = next[j + 1];

                    current[j] = 1 + Math.min(insert,
                                    Math.min(delete, replace));
                }
            }

            next = current;
        }

        return next[0];
    }
}
```

---

# Complexity

- Time : **O(m × n)**
- Space : **O(n)**

# Key Interview Points

- The DP state is defined by the current indices in both strings.
- When characters match, move diagonally without any cost.
- When characters differ, consider all three operations: **Insert**, **Delete**, and **Replace**, then choose the minimum.
- The base cases handle the situation where one string has been completely processed.
- The tabulation solution fills the table from the bottom-right toward the top-left.
- The problem can be space-optimized to **O(n)** because each row depends only on the next row.
- Time Complexity: **O(m × n)**
- Space Complexity: **O(n)** (optimized)
