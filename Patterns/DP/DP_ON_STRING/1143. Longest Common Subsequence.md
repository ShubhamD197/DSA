
# LeetCode 1143 — Longest Common Subsequence

**Difficulty:** Medium  
**Topic:** Dynamic Programming / Strings

---

# Problem Statement

Given two strings `text1` and `text2`, return the length of their **Longest Common Subsequence (LCS)**.

A **subsequence** is a sequence that can be obtained by deleting some characters from a string without changing the order of the remaining characters.

For example:

```text
"abcde" → "ace"
````

`"ace"` is a subsequence of `"abcde"`.

But:

```text
"abcde" → "aec"
```

is not a subsequence because the order is changed.

---

```text
Input:
text1 = "abcde"
text2 = "ace"

Output:
3
```

Explanation:

```text
abcde
↓ ↓ ↓
a c e
```

The longest common subsequence is:

```text
"ace"
```

Length:

```text
3
```

# Example 2

```text
Input:
text1 = "abc"
text2 = "abc"

Output:
3
```

The entire strings are the same.

```text
LCS = "abc"
```

Answer:

```text
3
```

```text
Input:
text1 = "abc"

0
```

There are no common characters.

# Main Idea

We compare characters from both strings.

Suppose:

```text
text1[i] == text2[j]
```

Then we found a matching character.

So:

```text
1 + LCS(remaining characters)
```

If:

```text
text1[i] != text2[j]
```

We have two choices:

```text
Skip text1[i]
```

or:

```text
Skip text2[j]
```

Therefore:

```text
LCS = max(
    skip text1[i],
    skip text2[j]
)
```

This gives us the basic DP pattern.

---

# Approach 1: Recursion

## Java Code

```java
class Solution {

    public int longestCommonSubsequence(
            String text1,
            String text2) {

        return solve(
                text1,
                text2,
                0,
                0
        );
    }

    private int solve(
            String text1,
            String text2,
            int i,
            int j) {

        // No characters left
        if (i == text1.length()
                || j == text2.length()) {

            return 0;
        }

        // Characters match
        if (text1.charAt(i)
                == text2.charAt(j)) {

            return 1 + solve(
                    text1,
                    text2,
                    i + 1,
                    j + 1
            );
        }

        // Characters don't match
        int skipText1 = solve(
                text1,
                text2,
                i + 1,
                j
        );

        int skipText2 = solve(
                text1,
                text2,
                i,
                j + 1
        );

        return Math.max(
                skipText1,
                skipText2
        );
    }
}
```

Start:

```text

```

Characters match:


```text
LCS = 1 + solve(1, 1)
```

Now:

```text

text2 = "ce"
```

Compare:

```text
'b' != 'c'
```

We have two choices:

```text
Skip 'b'
```

or:

```text
Skip 'c'
```

The better choice is to skip `'b'`.

Now:

```text
'c' == 'c'
```

Add `1`.

Then:

```text
'e' == 'e'
```

Add `1`.

Final:

```text
1 + 1 + 1 = 3

```

# Complexity

If characters don't match, recursion branches into two possibilities.

```text
Time: O(2^(m+n))
Space: O(m+n)
```

This is inefficient because the same states are calculated repeatedly.

For example:

```text
solve(i, j)
```

can be reached through multiple recursion paths.

So we use **Memoization**.

---

# Approach 2: Memoization

## Idea

The result depends only on:

```text
i
j
```

So our DP state is:

```text
dp[i][j]
```

Meaning:

> LCS length starting from `text1[i]` and `text2[j]`.

If we already calculated a state, return the stored result.

---

## Java Code

```java
class Solution {

    public int longestCommonSubsequence(
            String text1,
            String text2) {

        int m = text1.length();
        int n = text2.length();

        int[][] dp = new int[m][n];

        for (int i = 0; i < m; i++) {
            Arrays.fill(dp[i], -1);
        }

        return solve(
                text1,
                text2,
                0,
                0,
                dp
        );
    }

    private int solve(
            String text1,
            String text2,
            int i,
            int j,
            int[][] dp) {

        if (i == text1.length()
                || j == text2.length()) {

            return 0;
        }

        if (dp[i][j] != -1) {
            return dp[i][j];
        }

        if (text1.charAt(i)
                == text2.charAt(j)) {

            return dp[i][j] =
                    1 + solve(
                            text1,
                            text2,
                            i + 1,
                            j + 1,
                            dp
                    );
        }

        int skipText1 = solve(
                text1,
                text2,
                i + 1,
                j,
                dp
        );

        int skipText2 = solve(
                text1,
                text2,
                i,
                j + 1,
                dp
        );

        return dp[i][j] =
                Math.max(
                        skipText1,
                        skipText2
                );
    }
}
```

# Complexity

There are:

```text
m × n
```

possible states.

Each state is calculated only once.

```text
Time: O(m × n)
Space: O(m × n) + O(m + n)
```

The additional `O(m + n)` is recursion stack space.

# Approach 3: Tabulation

## Idea

Instead of starting from:

```text
i = 0
j = 0
```

we solve the problem from the end.

We create:

```text
dp[m + 1][n + 1]
```

where:

```text
dp[i][j]
```

means:

> LCS length of the first `i` characters of `text1` and the first `j` characters of `text2`.

The extra row and column represent an empty string.

---

## Base Case

If either string is empty:

```text
LCS = 0
```

So:

```text
dp[0][j] = 0
dp[i][0] = 0
```

---

## Transition

If characters match:

```text
text1[i - 1] == text2[j - 1]
```

Then:

```text
dp[i][j] =
1 + dp[i - 1][j - 1]
```

If they don't match:

```text
dp[i][j] =
max(
    dp[i - 1][j],
    dp[i][j - 1]
)
```

---

## Java Code

```java
class Solution {

    public int longestCommonSubsequence(
            String text1,
            String text2) {

        int m = text1.length();
        int n = text2.length();

        int[][] dp =
                new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {

            for (int j = 1; j <= n; j++) {

                if (text1.charAt(i - 1)
                        == text2.charAt(j - 1)) {

                    dp[i][j] =
                            1 + dp[i - 1][j - 1];

                } else {

                    dp[i][j] =
                            Math.max(
                                    dp[i - 1][j],
                                    dp[i][j - 1]
                            );
                }
            }
        }

        return dp[m][n];
    }
}
```

```text

```

Characters match.

So:

```text
dp[i][j]
= 1 + dp[i - 1][j - 1]
```

For the `c` characters:

```text
dp[3][2]
= 1 + dp[2][1]
= 1 + 1
= 2
```

The LCS so far is:

```text
"ac"
```

Later, when `e` matches:

```text
dp[5][3]
= 1 + dp[4][2]
= 1 + 2
= 3
```

Therefore:

```text
LCS = "ace"
Length = 3
```

# Approach 4: Space Optimized DP

## Observation

For calculating:

```text
dp[i][j]
```

we only need:

```text
dp[i - 1][j]
dp[i][j - 1]
dp[i - 1][j - 1]
```

Therefore, we don't need the entire 2D table.

We can use two arrays:

```text
previous
current
```

---

## Java Code

```java
class Solution {

    public int longestCommonSubsequence(
            String text1,
            String text2) {

        int m = text1.length();
        int n = text2.length();

        int[] previous = new int[n + 1];
        int[] current = new int[n + 1];

        for (int i = 1; i <= m; i++) {

            for (int j = 1; j <= n; j++) {

                if (text1.charAt(i - 1)
                        == text2.charAt(j - 1)) {

                    current[j] =
                            1 + previous[j - 1];

                } else {

                    current[j] =
                            Math.max(
                                    previous[j],
                                    current[j - 1]
                            );
                }
            }

            previous = current;
            current = new int[n + 1];
        }

        return previous[n];
    }
}
```

# Comparison

| Approach        | Time       | Space    | Best For              |
| --------------- | ---------- | -------- | --------------------- |
| Recursion       | O(2^(m+n)) | O(m+n)   | Understanding         |
| Memoization     | O(m × n)   | O(m × n) | Top-down DP           |
| Tabulation      | O(m × n)   | O(m × n) | Easy DP visualization |
| Space Optimized | O(m × n)   | O(n)     | Best optimized        |

# Which Approach Is Better?

### Best for Understanding

**Recursion**

Think:

```text
Characters Match
    ↓
Take both

Characters Don't Match
    ↓
Skip text1 OR Skip text2
```

---

### Best for Learning DP

**Memoization**

It directly converts the recursion into DP by caching:

```text
dp[i][j]
```

---

### Best for Interviews

**Tabulation**

The transition is easy to explain:

```text
if characters match:
    1 + diagonal

else:
    max(top, left)
```

---

### Best Space Complexity

**Space Optimized DP**

```text
Time: O(m × n)
Space: O(n)
```

This is the most space-efficient solution.

---

# Core Pattern to Remember

```text
                 text1[i] == text2[j] ?
                        /        \
                      YES        NO
                       |          |
                    + 1          MAX
                       |        /   \
                  diagonal    top   left
```

For **Memoization**:

```text
match:
    1 + solve(i + 1, j + 1)

not match:
    max(
        solve(i + 1, j),
        solve(i, j + 1)
    )
```

For **Tabulation**:

```text
match:
    dp[i][j] = 1 + dp[i-1][j-1]

not match:
    dp[i][j] =
        max(
            dp[i-1][j],
            dp[i][j-1]
        )
```
