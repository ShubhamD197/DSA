# LeetCode 1143 — Longest Common Subsequence

**Difficulty:** Medium  
**Topics:** Dynamic Programming, String

---

## Problem Statement

Given two strings `text1` and `text2`, return the length of their **Longest Common Subsequence (LCS)**.

A **subsequence** is a sequence that can be obtained by deleting some characters from a string without changing the relative order of the remaining characters.

For example:

```text
"abcde" → "ace"
```

`"ace"` is a subsequence of `"abcde"`.

But:

```text
"abcde" → "aec"
```

is not a subsequence because the order of characters has changed.

---

## Example 1

```text
Input:
text1 = "abcde"
text2 = "ace"

Output:
3
```

Explanation:

```text
text1 = a b c d e
         ↓   ↓   ↓
text2 =  a   c   e
```

Longest Common Subsequence:

```text
"ace"
```

Length:

```text
3
```

---

## Example 2

```text
Input:
text1 = "abc"
text2 = "abc"

Output:
3
```

The entire string is common.

```text
LCS = "abc"
```

---

## Example 3

```text
Input:
text1 = "abc"
text2 = "def"

Output:
0
```

There are no common characters.

# Approach 1: Recursion

## Intuition

We compare characters at index `i` and `j`.

### Case 1: Characters are equal

If:

```java
text1.charAt(i) == text2.charAt(j)
```

We include that character in our LCS.

So:

```text
1 + solve(i + 1, j + 1)
```

### Case 2: Characters are different

We have two choices:

```text
1. Skip text1[i]
2. Skip text2[j]
```

So:

```text
max(
    solve(i + 1, j),
    solve(i, j + 1)
)
```

---

## Java Code

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        return solve(text1, text2, 0, 0);
    }

    private int solve(String text1, String text2, int i, int j) {
        if (i == text1.length() || j == text2.length()) {
            return 0;
        }

        if (text1.charAt(i) == text2.charAt(j)) {
            return 1 + solve(text1, text2, i + 1, j + 1);
        }

        int skipText1 = solve(text1, text2, i + 1, j);
        int skipText2 = solve(text1, text2, i, j + 1);

        return Math.max(skipText1, skipText2);
    }
}
```

---

## Dry Run

Take:

```text
text1 = "abcde"
text2 = "ace"
```

Start:

```text
i = 0 → 'a'
j = 0 → 'a'
```

Characters match:

```text
'a' == 'a'
```

So we take `'a'`.

```text
LCS = 1 + solve(1, 1)
```

Now:

```text
text1[i] = 'b'
text2[j] = 'c'
```

They don't match.

We have two choices:

```text
Skip 'b'
```

or:

```text
Skip 'c'
```

The best path is:

```text
'a' → 'a'
'c' → 'c'
'e' → 'e'
```

Therefore:

```text
LCS = "ace"
Answer = 3
```

---

## Complexity

```text
Time: O(2^(m+n))
Space: O(m+n)
```

The recursive solution is inefficient because the same `(i, j)` states are calculated multiple times.

So we optimize it using **Memoization**.

---

# Approach 2: Memoization

## Intuition

The result depends on two variables:

```text
i
j
```

So our DP state is:

```text
dp[i][j]
```

It represents the LCS length starting from:

```text
text1[i]
text2[j]
```

If we have already calculated `dp[i][j]`, we directly return it.

---

## Java Code

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        int[][] dp = new int[m][n];

        for (int i = 0; i < m; i++) {
            Arrays.fill(dp[i], -1);
        }

        return solve(text1, text2, 0, 0, dp);
    }

    private int solve(String text1, String text2, int i, int j, int[][] dp) {
        if (i == text1.length() || j == text2.length()) {
            return 0;
        }

        if (dp[i][j] != -1) {
            return dp[i][j];
        }

        if (text1.charAt(i) == text2.charAt(j)) {
            return dp[i][j] = 1 + solve(text1, text2, i + 1, j + 1, dp);
        }

        int skipText1 = solve(text1, text2, i + 1, j, dp);
        int skipText2 = solve(text1, text2, i, j + 1, dp);

        return dp[i][j] = Math.max(skipText1, skipText2);
    }
}
```

---

## Dry Run

Input:

```text
text1 = "abcde"
text2 = "ace"
```

We start:

```text
solve(0, 0)
```

Compare:

```text
'a' == 'a'
```

Therefore:

```text
dp[0][0] = 1 + dp[1][1]
```

Next:

```text
'b' != 'c'
```

So:

```text
dp[1][1] = max(
    dp[2][1],
    dp[1][2]
)
```

The recursion explores both possibilities, but once a state has been calculated, it is stored in `dp`.

Eventually:

```text
dp[0][0] = 3
```

Answer:

```text
3
```

---

## Complexity

There are `m × n` possible states.

Each state is calculated only once.

```text
Time: O(m × n)
Space: O(m × n) + O(m+n)
```

The additional `O(m+n)` is the recursion stack.

# Approach 3: Tabulation

## Intuition

Instead of recursion, we build the DP table from bottom to top.

We create:

```java
int[][] dp = new int[m + 1][n + 1];
```

Here:

```text
dp[i][j]
```

means:

> LCS length between the first `i` characters of `text1` and the first `j` characters of `text2`.

---

## Base Case

If one string is empty:

```text
LCS = 0
```

Therefore:

```text
dp[0][j] = 0
dp[i][0] = 0
```

Java automatically initializes these values to `0`.

---

## Transition

If characters match:

```java
text1.charAt(i - 1) == text2.charAt(j - 1)
```

Then:

```text
dp[i][j] = 1 + dp[i-1][j-1]
```

If they don't match:

```text
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

---

## Java Code

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = 1 + dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

```text

text2 = "ace"
```

```text
       ""  a  c  e
    ----------------
""  |  0  0  0  0
```

## Understanding Some Important Cells

### `dp[1][1]`

Characters:

```text
'a' == 'a'
```

So:

```text
dp[1][1] = 1 + dp[0][0]
         = 1
```

---

### `dp[3][2]`

Characters:

```text
'c' == 'c'
```

So:

```text
dp[3][2] = 1 + dp[2][1]
         = 1 + 1
         = 2
```

The LCS is now:

```text
"ac"
```

---

### `dp[5][3]`

Characters:

```text
'e' == 'e'
```

So:

```text
dp[5][3] = 1 + dp[4][2]
         = 1 + 2
         = 3
```

Final LCS:

```text
"ace"
```

Answer:

```text
3
```

# Approach 4: Space Optimized DP

## Observation

To calculate:

```text
dp[i][j]
```

we only need:

```text
dp[i-1][j]     // Previous row
dp[i][j-1]     // Current row
dp[i-1][j-1]   // Previous row diagonal
```

Therefore, we don't need the complete 2D array.

We can use two 1D arrays:

```text
previous
current
```

---

## Java Code

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        int[] previous = new int[n + 1];
        int[] current = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    current[j] = 1 + previous[j - 1];
                } else {
                    current[j] = Math.max(previous[j], current[j - 1]);
                }
            }

            previous = current;
            current = new int[n + 1];
        }

        return previous[n];
    }
}
```

---

## Dry Run

Input:

```text
text1 = "abcde"
text2 = "ace"
```

Initially:

```text
previous = [0, 0, 0, 0]
```

After processing `'a'`:

```text
current = [0, 1, 1, 1]
```

After processing `'b'`:

```text
current = [0, 1, 1, 1]
```

After processing `'c'`:

```text
current = [0, 1, 2, 2]
```

After processing `'d'`:

```text
current = [0, 1, 2, 2]
```

After processing `'e'`:

```text
current = [0, 1, 2, 3]
```

Final:

```text
Answer = 3
```

# Comparison

| Approach | Time | Space | Best Use |
|---|---:|---:|---|
| Recursion | O(2^(m+n)) | O(m+n) | Understanding |
| Memoization | O(m × n) | O(m × n) | Top-Down DP |
| Tabulation | O(m × n) | O(m × n) | Easy to Understand |
| Space Optimized | O(m × n) | O(n) | Best Optimization |

---

# Which One Is Better?

### Recursion

Good for understanding the basic logic, but too slow.

```text
Match → Take Both
No Match → Skip Either One
```

### Memoization

Better because repeated states are stored.

```text
Time: O(m × n)
```

### Tabulation

Usually the best approach to learn and explain in interviews because the DP table clearly shows the transition.

### Space Optimized

Best when only the LCS **length** is required.

```text
Time: O(m × n)
Space: O(n)
```

---

# Core Pattern

The most important thing to remember is:

```text
If characters match:

dp[i][j] = 1 + dp[i-1][j-1]
```

```text
If characters don't match:

dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

Think of it as:

```text
Same Character
      ↓
Take it
      ↓
Move diagonally

Different Character
      ↓
Skip text1 character OR text2 character
      ↓
Take maximum
```

---

# Final Recommended Solution

For LeetCode 1143, the **Tabulation approach** is the best one to learn first.

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length();
        int n = text2.length();

        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = 1 + dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

**Time Complexity:** `O(m × n)`  
**Space Complexity:** `O(m × n)`

> **Key takeaway:** When the current characters match, take the character and move diagonally. When they don't match, skip one character from either string and take the better result.
