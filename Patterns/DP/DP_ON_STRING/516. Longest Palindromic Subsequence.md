# 516. Longest Palindromic Subsequence

**Difficulty:** Medium

**Topic:** Dynamic Programming (String DP)

---

# Problem Statement

Given a string `s`, return the **length of the longest palindromic subsequence**.

A **subsequence** is obtained by deleting zero or more characters without changing the order of the remaining characters.

A palindrome is a string that reads the same forward and backward.

---

# Example 1

```text
Input

s = "bbbab"

Output

4
```

Explanation

One longest palindromic subsequence is

```text
bbbb
```

Length = 4

---

# Example 2

```text
Input

s = "cbbd"

Output

2
```

Explanation

Longest palindromic subsequence

```text
bb
```

Length = 2

---

# Understanding the Problem

Unlike **Longest Palindromic Substring**, the characters **do not need to be contiguous**.

Example

```text
String

a b c d a

Subsequence

a   c   a

Valid ✔
```

---

# Key Observation

Consider two pointers

```text
i

↓

a b c d b a

          ↑

          j
```

We compare the characters at both ends.

### Case 1

```text
s[i] == s[j]
```

Both characters become part of the palindrome.

```text
Answer

=

2 + solve(i+1, j-1)
```

---

### Case 2

```text
s[i] != s[j]
```

We have to skip one character.

```text
max(

solve(i+1, j),

solve(i, j-1)

)
```

---

# Recurrence

```text
solve(i, j)

=

if s[i] == s[j]

↓

2 + solve(i+1, j-1)

else

↓

max(

solve(i+1, j),

solve(i, j-1)

)
```

---

# Base Cases

If

```text
i > j
```

No characters remain.

Return

```text
0
```

---

If

```text
i == j
```

Only one character remains.

A single character is always a palindrome.

Return

```text
1
```

---

# Approach 1 : Brute Force Recursion

## Idea

Recursively compare the first and last characters.

Explore both possibilities when they do not match.

---

## Java Code

```java
class Solution {

    public int longestPalindromeSubseq(String s) {
        return solve(s, 0, s.length() - 1);
    }

    private int solve(String s, int left, int right) {

        if (left > right)
            return 0;

        if (left == right)
            return 1;

        if (s.charAt(left) == s.charAt(right)) {
            return 2 + solve(s, left + 1, right - 1);
        }

        return Math.max(
                solve(s, left + 1, right),
                solve(s, left, right - 1)
        );
    }
}
```

# Approach 2 : Memoization (Top-Down DP)

## Idea

The recursive state is

```text
(left, right)
```

Store every computed answer.

---

## DP State

```text
dp[left][right]
```

=

Longest palindromic subsequence between

```text
left

and

right
```

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int longestPalindromeSubseq(String s) {

        int n = s.length();

        int[][] dp = new int[n][n];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        return solve(s, 0, n - 1, dp);
    }

    private int solve(String s, int left, int right, int[][] dp) {

        if (left > right)
            return 0;

        if (left == right)
            return 1;

        if (dp[left][right] != -1)
            return dp[left][right];

        if (s.charAt(left) == s.charAt(right)) {

            return dp[left][right] =
                    2 + solve(s, left + 1, right - 1, dp);
        }

        return dp[left][right] = Math.max(
                solve(s, left + 1, right, dp),
                solve(s, left, right - 1, dp)
        );
    }
}
```

# Approach 3 : Tabulation (Bottom-Up)

## Idea

The recurrence depends on

```text
i+1

j-1

i+1

j

i

j-1
```

Therefore,

fill the DP table **from bottom to top**.

---

## DP State

```text
dp[i][j]

=

Longest Palindromic Subsequence

between i and j
```

---

## Java Code

```java
class Solution {

    public int longestPalindromeSubseq(String s) {

        int n = s.length();

        int[][] dp = new int[n][n];

        for (int i = 0; i < n; i++)
            dp[i][i] = 1;

        for (int i = n - 1; i >= 0; i--) {

            for (int j = i + 1; j < n; j++) {

                if (s.charAt(i) == s.charAt(j)) {

                    dp[i][j] = 2 + dp[i + 1][j - 1];

                } else {

                    dp[i][j] = Math.max(
                            dp[i + 1][j],
                            dp[i][j - 1]
                    );
                }
            }
        }

        return dp[0][n - 1];
    }
}
```

# Approach 4 : Space Optimization

## Observation

Each row only depends on

- Current row
- Previous row

Use two 1D arrays.

---

## Java Code

```java
class Solution {

    public int longestPalindromeSubseq(String s) {

        int n = s.length();

        int[] next = new int[n];

        for (int i = n - 1; i >= 0; i--) {

            int[] current = new int[n];
            current[i] = 1;

            for (int j = i + 1; j < n; j++) {

                if (s.charAt(i) == s.charAt(j)) {

                    current[j] = 2 + next[j - 1];

                } else {

                    current[j] = Math.max(
                            next[j],
                            current[j - 1]
                    );
                }
            }

            next = current;
        }

        return next[n - 1];
    }
}
```

# Alternative Approach (LCS Trick)

## Observation

A palindrome reads the same forward and backward.

Therefore,

```text
Longest Palindromic Subsequence

=

LCS(

s,

reverse(s)

)
```

---

## Java Code

```java
class Solution {

    public int longestPalindromeSubseq(String s) {

        String rev = new StringBuilder(s).reverse().toString();

        int n = s.length();

        int[][] dp = new int[n + 1][n + 1];

        for (int i = 1; i <= n; i++) {

            for (int j = 1; j <= n; j++) {

                if (s.charAt(i - 1) == rev.charAt(j - 1)) {

                    dp[i][j] = 1 + dp[i - 1][j - 1];

                } else {

                    dp[i][j] = Math.max(
                            dp[i - 1][j],
                            dp[i][j - 1]
                    );
                }
            }
        }

        return dp[n][n];
    }
}
```

---

## Complexity

- Time : **O(n²)**
- Space : **O(n²)**

# DP Pattern Learned

This problem introduces the classic **Interval DP** pattern.

State

```text
dp[i][j]
```

=

Longest Palindromic Subsequence

inside

```text
i...j
```

Transition

```text
If same

↓

2 + dp[i+1][j-1]

----------------

Else

↓

max(

dp[i+1][j],

dp[i][j-1]

)
```

---

# Relationship with LCS

```text
Longest Palindromic Subsequence

=

Longest Common Subsequence

between

Original String

and

Reversed String
```

This is why many interviewers expect both approaches.

---

# Key Interview Points

- This is an **Interval DP** problem where the state is defined by two indices `(i, j)`.
- If the characters at both ends match, include both in the palindrome and move inward.
- If they do not match, skip one end and take the maximum result.
- Fill the DP table **from bottom to top** because each state depends on smaller intervals.
- An alternative solution is to compute the **Longest Common Subsequence (LCS)** between the string and its reverse.
- The optimal DP solution runs in **O(n²)** time.
