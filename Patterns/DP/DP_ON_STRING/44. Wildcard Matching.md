# 44. Wildcard Matching

**Difficulty:** Hard

**Topic:** Dynamic Programming (String DP)

---

# Problem Statement

Given an input string `s` and a pattern `p`, implement wildcard pattern matching with support for:

- `'?'` matches **exactly one** character.
- `'*'` matches **any sequence of characters**, including an empty sequence.

Return `true` if the **entire string** matches the pattern.

private boolean allStars(String pattern, int index) {

    while (index < pattern.length()) {

        if (pattern.charAt(index) != '*')
            return false;

        index++;
    }

    return true;
}

# Approach 1 : Brute Force Recursion

## Java Code

```java
class Solution {

    public boolean isMatch(String s, String p) {
        return solve(s, p, 0, 0);
    }

    private boolean solve(String s, String p, int i, int j) {

        if (i == s.length() && j == p.length())
            return true;

        if (j == p.length())
            return false;

        if (i == s.length())
            return allStars(p, j);

        if (s.charAt(i) == p.charAt(j) || p.charAt(j) == '?') {
            return solve(s, p, i + 1, j + 1);
        }

        if (p.charAt(j) == '*') {

            return solve(s, p, i, j + 1)
                    || solve(s, p, i + 1, j);
        }

        return false;
    }

    private boolean allStars(String p, int index) {

        while (index < p.length()) {

            if (p.charAt(index) != '*')
                return false;

            index++;
        }

        return true;
    }
}
```

# Approach 2 : Memoization (Top-Down DP)

## DP State

```text
dp[i][j]
```

=

Can

```text
s[i...]

match

p[j...]
```

Store

```text
1 = true

0 = false

-1 = not computed
```

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public boolean isMatch(String s, String p) {

        int[][] dp = new int[s.length() + 1][p.length() + 1];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        return solve(s, p, 0, 0, dp);
    }

    private boolean solve(String s, String p,
                          int i, int j,
                          int[][] dp) {

        if (i == s.length() && j == p.length())
            return true;

        if (j == p.length())
            return false;

        if (i == s.length())
            return allStars(p, j);

        if (dp[i][j] != -1)
            return dp[i][j] == 1;

        boolean ans;

        if (s.charAt(i) == p.charAt(j) || p.charAt(j) == '?') {

            ans = solve(s, p, i + 1, j + 1, dp);

        } else if (p.charAt(j) == '*') {

            ans = solve(s, p, i, j + 1, dp)
                    || solve(s, p, i + 1, j, dp);

        } else {

            ans = false;
        }

        dp[i][j] = ans ? 1 : 0;

        return ans;
    }

    private boolean allStars(String p, int index) {

        while (index < p.length()) {

            if (p.charAt(index) != '*')
                return false;

            index++;
        }

        return true;
    }
}
```

---

## Complexity

- Time : **O(m × n)**
- Space :
  - DP Table : **O(m × n)**
  - Recursion Stack : **O(m + n)**

# Approach 3 : Tabulation (Bottom-Up)

## DP State

```text
dp[i][j]
```

=

Can

```text
s[i...]

match

p[j...]
```

---

## Initialization

```text
dp[m][n] = true
```

When string is finished,

remaining pattern must be all '*'.

---

## Java Code

```java
class Solution {

    public boolean isMatch(String s, String p) {

        int m = s.length();
        int n = p.length();

        boolean[][] dp = new boolean[m + 1][n + 1];

        dp[m][n] = true;

        for (int j = n - 1; j >= 0; j--) {
            dp[m][j] = p.charAt(j) == '*' && dp[m][j + 1];
        }

        for (int i = m - 1; i >= 0; i--) {

            for (int j = n - 1; j >= 0; j--) {

                if (s.charAt(i) == p.charAt(j) || p.charAt(j) == '?') {

                    dp[i][j] = dp[i + 1][j + 1];

                } else if (p.charAt(j) == '*') {

                    dp[i][j] = dp[i][j + 1] || dp[i + 1][j];

                } else {

                    dp[i][j] = false;
                }
            }
        }

        return dp[0][0];
    }
}
```

# Approach 4 : Space Optimization

## Observation

Each row depends only on:

- Current row
- Next row

So two arrays are enough.

---

## Java Code

```java
class Solution {

    public boolean isMatch(String s, String p) {

        int m = s.length();
        int n = p.length();

        boolean[] next = new boolean[n + 1];
        next[n] = true;

        for (int j = n - 1; j >= 0; j--) {
            next[j] = p.charAt(j) == '*' && next[j + 1];
        }

        for (int i = m - 1; i >= 0; i--) {

            boolean[] current = new boolean[n + 1];

            for (int j = n - 1; j >= 0; j--) {

                if (s.charAt(i) == p.charAt(j) || p.charAt(j) == '?') {

                    current[j] = next[j + 1];

                } else if (p.charAt(j) == '*') {

                    current[j] = current[j + 1] || next[j];

                }
            }

            next = current;
        }

        return next[0];
    }
}
```

---

## Complexity

- Time : **O(m × n)**
- Space : **O(n)**

# Difference Between '?' and '*'

| Wildcard | Meaning |
|----------|---------|
| `?` | Matches exactly **one** character |
| `*` | Matches **zero or more** characters |

---

# Relationship with Regular Expression Matching (LeetCode 10)

| Wildcard Matching (44) | Regular Expression Matching (10) |
|------------------------|----------------------------------|
| `?` matches any one character | `.` matches any one character |
| `*` matches any sequence directly | `*` repeats the **previous character** |
| Simpler wildcard rules | Regex rules are more complex |

# Key Interview Points

- The DP state is `(i, j)`, representing whether `s[i...]` matches `p[j...]`.
- `?` always matches **exactly one** character.
- `*` has two possibilities:
  - Match **zero** characters → move only the pattern pointer.
  - Match **one or more** characters → move only the string pointer.
- When the input string is exhausted, the remaining pattern must contain **only `*` characters** to produce a match.
- The tabulation solution fills the table from **bottom-right to top-left**.
- The solution can be space-optimized to **O(n)**.
- Time Complexity: **O(m × n)**
- Space Complexity: **O(n)** (optimized)
