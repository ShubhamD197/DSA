# 300. Longest Increasing Subsequence (LIS)

**Difficulty:** Medium

**Topic:** Dynamic Programming

---

# Problem Statement

Given an integer array `nums`, return the **length of the longest strictly increasing subsequence**.

A **subsequence** is a sequence that can be derived from an array by deleting some or no elements **without changing the order** of the remaining elements.

A subsequence is **strictly increasing** if every next element is greater than the previous one.

---

# Example 1

```text
Input

nums = [10,9,2,5,3,7,101,18]

Output

4
```

Explanation

One possible LIS is

```text
2 → 3 → 7 → 101
```

Length = 4

---

# Example 2

```text
Input

nums = [0,1,0,3,2,3]

Output

4
```

LIS

```text
0 → 1 → 2 → 3
```

---

# Example 3

```text
Input

nums = [7,7,7,7,7]

Output

1
```

Only one element can be chosen because the sequence must be **strictly increasing**.

---

# Understanding the DP State

At every index we have two choices:

1. **Take** the current element (only if it is greater than the previously chosen element).
2. **Skip** the current element.

So our state becomes:

```text
(index, previousIndex)
```

where

```text
index = current position

previousIndex = index of last chosen element
```

If no element has been chosen yet,

```text
previousIndex = -1
```

---

# Recurrence

```text
solve(index, prev)

=

max(

Take Current,

Skip Current

)
```

Take is allowed only if

```text
prev == -1

OR

nums[index] > nums[prev]
```

---

# Approach 1 : Brute Force Recursion

## Idea

Try both possibilities for every element.

- Pick
- Not Pick

Return the maximum length.

---

## Recursive Tree

Example

```text
nums = [3,1,2]
```

```text
solve(0,-1)

├── Take 3

│      ↓

│   solve(1,0)

│

└── Skip

       ↓

   solve(1,-1)
```

Many states repeat.

---

## Java Code

```java
class Solution {

    public int lengthOfLIS(int[] nums) {
        return solve(nums, 0, -1);
    }

    private int solve(int[] nums, int index, int prev) {

        if (index == nums.length)
            return 0;

        int take = 0;

        if (prev == -1 || nums[index] > nums[prev]) {
            take = 1 + solve(nums, index + 1, index);
        }

        int skip = solve(nums, index + 1, prev);

        return Math.max(take, skip);
    }
}
```

---

## Dry Run

```text
nums = [3,1,2]
```

```

↓

1

Skip

↓

Take 1

↓

Take 2

↓

2
```

```text

```

```text

```

---

## Complexity

- Time : **O(2ⁿ)**
- Space : **O(n)**

# Approach 2 : Memoization (Top-Down DP)

## Idea

The same `(index, prev)` state is solved multiple times.

Store the answer in a DP table.

Since `prev` can be `-1`, shift it by 1.

```text
Column

prev + 1
```

---

## DP State

```text
dp[index][prev + 1]
```

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int lengthOfLIS(int[] nums) {

        int n = nums.length;

        int[][] dp = new int[n][n + 1];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        return solve(nums, 0, -1, dp);
    }

    private int solve(int[] nums, int index, int prev, int[][] dp) {

        if (index == nums.length)
            return 0;

        if (dp[index][prev + 1] != -1)
            return dp[index][prev + 1];

        int take = 0;

        if (prev == -1 || nums[index] > nums[prev]) {
            take = 1 + solve(nums, index + 1, index, dp);
        }

        int skip = solve(nums, index + 1, prev, dp);

        return dp[index][prev + 1] = Math.max(take, skip);
    }
}
```

---

## Dry Run

```text
nums = [3,1,2]
```

Memo Table

```text
(index,prev)

(0,-1)

↓

2

(1,-1)

↓

2

(2,1)

↓

1
```

Repeated states are solved only once.

---

## Complexity

- Time : **O(n²)**
- Space :
  - DP Table : **O(n²)**
  - Recursion Stack : **O(n)**

# Approach 3 : Tabulation (Bottom-Up)

## Idea

Convert the memoization solution into iterative DP.

Fill states from the last index towards the first.

---

## Java Code

```java
class Solution {

    public int lengthOfLIS(int[] nums) {

        int n = nums.length;

        int[][] dp = new int[n + 1][n + 1];

        for (int index = n - 1; index >= 0; index--) {

            for (int prev = index - 1; prev >= -1; prev--) {

                int take = 0;

                if (prev == -1 || nums[index] > nums[prev]) {
                    take = 1 + dp[index + 1][index + 1];
                }

                int skip = dp[index + 1][prev + 1];

                dp[index][prev + 1] = Math.max(take, skip);
            }
        }

        return dp[0][0];
    }
}
```

---

## Dry Run

```text
nums = [3,1,2]
```

Final DP stores

```text
dp[0][0]

=

2
```

Answer

```text
2
```

---

## Complexity

- Time : **O(n²)**
- Space : **O(n²)**

# Approach 4 : Classic 1D DP (Most Common Interview DP)

## Idea

Let

```text
dp[i]
```

represent

> Length of the LIS ending at index `i`.

Transition

```text
dp[i]

=

1 + dp[j]

where

j < i

and

nums[j] < nums[i]
```

Initially,

every element itself forms an LIS of length `1`.

---

## Java Code

```java
class Solution {

    public int lengthOfLIS(int[] nums) {

        int n = nums.length;

        int[] dp = new int[n];

        int answer = 1;

        for (int i = 0; i < n; i++) {

            dp[i] = 1;

            for (int j = 0; j < i; j++) {

                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }

            answer = Math.max(answer, dp[i]);
        }

        return answer;
    }
}
```

---

## Dry Run

```text
nums = [10,9,2,5,3,7,101,18]
```

| Index | Value | dp |
|------|------|----|
|0|10|1|
|1|9|1|
|2|2|1|
|3|5|2|
|4|3|2|
|5|7|3|
|6|101|4|
|7|18|4|

Final

```text

[1,1,1,2,2,3,4,4]
```


## Complexity

- Time : **O(n²)**
- Space : **O(n)**

# Approach 5 : Binary Search (Optimal)

## Idea

Maintain a list called `tails`.

`tails[i]` stores the **smallest possible tail** of an increasing subsequence of length `i + 1`.

For every number:

- If it is greater than the last element,
  append it.
- Otherwise,
  replace the first element greater than or equal to it using binary search.

> **Important:** `tails` is **not** the actual LIS. Its size equals the length of the LIS.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int lengthOfLIS(int[] nums) {

        List<Integer> tails = new ArrayList<>();

        for (int num : nums) {

            int left = 0;
            int right = tails.size();

            while (left < right) {

                int mid = left + (right - left) / 2;

                if (tails.get(mid) < num)
                    left = mid + 1;
                else
                    right = mid;
            }

            if (left == tails.size())
                tails.add(num);
            else
                tails.set(left, num);
        }

        return tails.size();
    }
}
```

# DP Transition (Pick / Not Pick)

```text
solve(index, prev)

                │
        ┌───────┴────────┐
        │                │
      Take             Skip
        │                │
1 + solve(i+1,i)   solve(i+1,prev)
        │                │
        └───────┬────────┘
                │
              Maximum
```

---

# Why does the Binary Search approach work?

The goal is **not** to store the actual subsequence.

Instead, we keep the **smallest possible tail** for every subsequence length.

Example

```text
tails

[2,3,7]
```

means

- There exists an increasing subsequence of length `1` ending with `2`.
- There exists an increasing subsequence of length `2` ending with `3`.
- There exists an increasing subsequence of length `3` ending with `7`.

A **smaller tail** is always better because it provides more opportunities to extend the subsequence later.

Therefore, replacing larger tails with smaller ones never decreases the LIS length.

---

# DP Pattern Learned

This problem introduces the **Take / Not Take with Previous State** DP pattern.

State

```text
(index, previousIndex)
```

Transition

```text
Take

↓

1 + solve(index + 1, index)

----------------

Skip

↓

solve(index + 1, previousIndex)

----------------

Take Maximum
```

This pattern is also used in:

- Longest String Chain (1048)
- Russian Doll Envelopes (354)
- Largest Divisible Subset (368)
- Number of Longest Increasing Subsequences (673)

---

# Key Interview Points

- The recursive state is `(index, previousIndex)`.
- Memoization converts the exponential recursion into **O(n²)**.
- The **1D DP** solution is the most commonly expected DP approach in interviews.
- The **Binary Search** solution is the optimal solution with **O(n log n)** time.
- Remember that the `tails` array **does not store the actual LIS**; it only guarantees that its size equals the LIS length.
