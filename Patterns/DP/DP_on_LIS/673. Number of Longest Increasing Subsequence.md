# 673. Number of Longest Increasing Subsequences

**Difficulty:** Medium

**Topic:** Dynamic Programming

---

# Problem Statement

Given an integer array `nums`, return the **number of longest increasing subsequences (LIS)**.

A subsequence is obtained by deleting some or no elements without changing the order of the remaining elements.

The subsequence must be **strictly increasing**.

---

# Example 1

```text
Input

nums = [1,3,5,4,7]

Output

2
```

Explanation

Longest Increasing Subsequences are

```text
1 → 3 → 5 → 7

1 → 3 → 4 → 7
```

Length = 4

Number of LIS = 2

---

# Example 2

```text
Input

nums = [2,2,2,2,2]

Output

5
```

Explanation

Every individual element is an LIS.

Length = 1

Count = 5

---

# Understanding the Problem

Unlike **LeetCode 300**, we need two things:

1. Length of the LIS.
2. Number of LIS having that maximum length.

Therefore, one DP array is **not enough**.

We maintain:

```text
length[i]
```

= Length of LIS ending at index `i`

and

```text
count[i]
```

= Number of LIS ending at index `i`

---

# DP State

For every index

```text
length[i]
```

stores

```text
Longest length ending at i
```

and

```text
count[i]
```

stores

```text
How many LIS end at i
```

Initially,

```text
length[i] = 1

count[i] = 1
```

because every element itself forms an increasing subsequence.

---

# Transition

For every

```text
j < i
```

If

```text
nums[j] < nums[i]
```

then we can extend the subsequence.

### Case 1

Found a longer subsequence

```text
length[j] + 1 > length[i]
```

Update

```text
length[i] = length[j] + 1

count[i] = count[j]
```

---

### Case 2

Found another subsequence with the same maximum length

```text
length[j] + 1 == length[i]
```

Add the counts

```text
count[i] += count[j]
```

---

# Why Two Arrays?

Example

```text
nums = [1,3,5,4,7]
```

At

```text
7
```

we can reach it from

```text
5

or

4
```

Both produce an LIS of length

```text
4
```

Therefore

```text
count =

count(from 5)

+

count(from 4)
```

---

# Approach : Dynamic Programming (1D)

## Java Code

```java
class Solution {

    public int findNumberOfLIS(int[] nums) {

        int n = nums.length;

        int[] length = new int[n];
        int[] count = new int[n];

        int maxLength = 1;

        for (int i = 0; i < n; i++) {

            length[i] = 1;
            count[i] = 1;

            for (int j = 0; j < i; j++) {

                if (nums[j] < nums[i]) {

                    if (length[j] + 1 > length[i]) {

                        length[i] = length[j] + 1;
                        count[i] = count[j];

                    } else if (length[j] + 1 == length[i]) {

                        count[i] += count[j];
                    }
                }
            }

            maxLength = Math.max(maxLength, length[i]);
        }

        int answer = 0;

        for (int i = 0; i < n; i++) {

            if (length[i] == maxLength)
                answer += count[i];
        }

        return answer;
    }
}
```

| Return LIS length | Return number of LIS |

# Why can't we use the Binary Search solution from LeetCode 300?

The Binary Search approach only keeps the **smallest possible tail** for each subsequence length.

Example

```text
tails

[2,3,7]
```

This tells us:

- An LIS of length `1` exists.
- An LIS of length `2` exists.
- An LIS of length `3` exists.

However, it **does not store how many different subsequences** produce those lengths.

Since the count information is lost, the Binary Search approach cannot be directly used to solve this problem.

# DP Pattern Learned

This problem extends the classic LIS DP.

For every index:

```text
length[i]

↓

Longest LIS ending here

----------------

count[i]

↓

Number of LIS ending here
```

Transition

```text
If longer

↓

Update length

Copy count

----------------

If same length

↓

Add counts
```

---

# Key Interview Points

- Maintain **two DP arrays**:
  - `length[i]` = length of LIS ending at `i`
  - `count[i]` = number of LIS ending at `i`
- When a **longer** subsequence is found:
  - Update the length.
  - Copy the count.
- When **another LIS of the same length** is found:
  - Add the counts.
- After processing all indices, sum the counts for every index whose LIS length equals the global maximum.
- Time Complexity: **O(n²)**
- Space Complexity: **O(n)**
