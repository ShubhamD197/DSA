# 1048. Longest String Chain

**Difficulty:** Medium

**Topic:** Dynamic Programming (LIS Variant)

---

# Problem Statement

You are given an array of strings `words`.

A word `A` is a **predecessor** of another word `B` if:

- `B` has exactly **one extra character** than `A`.
- By inserting exactly one character anywhere in `A`, we can obtain `B`.

Return the **length of the longest possible word chain**.

Instead of checking


we check

```text

```

# Predecessor Check

Two pointers.

Example

```text
word1 = abc

word2 = abac
```

```text
a == a

↓

b == b

↓

c != a

Skip

↓

c == c
```

Exactly one mismatch.

Valid predecessor.

---

## Java Function

```java
private boolean isPredecessor(String small, String large) {

    if (large.length() != small.length() + 1)
        return false;

    int i = 0;
    int j = 0;

    while (i < small.length() && j < large.length()) {

        if (small.charAt(i) == large.charAt(j)) {
            i++;
            j++;
        } else {
            j++;
        }
    }

    return i == small.length();
}
```

# Approach 1 : Brute Force Recursion

## Idea

Exactly like LIS.

State

```text
(index, previousIndex)
```

At every word

- Take it (if it forms a valid chain)
- Skip it

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int longestStrChain(String[] words) {

        Arrays.sort(words, (a, b) -> a.length() - b.length());

        return solve(words, 0, -1);
    }

    private int solve(String[] words, int index, int prev) {

        if (index == words.length)
            return 0;

        int take = 0;

        if (prev == -1 || isPredecessor(words[prev], words[index])) {
            take = 1 + solve(words, index + 1, index);
        }

        int skip = solve(words, index + 1, prev);

        return Math.max(take, skip);
    }

    private boolean isPredecessor(String small, String large) {

        if (large.length() != small.length() + 1)
            return false;

        int i = 0, j = 0;

        while (i < small.length() && j < large.length()) {

            if (small.charAt(i) == large.charAt(j)) {
                i++;
                j++;
            } else {
                j++;
            }
        }

        return i == small.length();
    }
}
```

---

## Complexity

- Time : **O(2ⁿ × L)**
- Space : **O(n)**

`L` = Maximum word length.

# Approach 2 : Memoization (Top-Down DP)

## Idea

The recursive state is

```text
(index, previousIndex)
```

Store the answer for each state.

As in LIS,

store

```text
prev + 1
```

to handle `-1`.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int longestStrChain(String[] words) {

        Arrays.sort(words, (a, b) -> a.length() - b.length());

        int n = words.length;

        int[][] dp = new int[n][n + 1];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        return solve(words, 0, -1, dp);
    }

    private int solve(String[] words, int index, int prev, int[][] dp) {

        if (index == words.length)
            return 0;

        if (dp[index][prev + 1] != -1)
            return dp[index][prev + 1];

        int take = 0;

        if (prev == -1 || isPredecessor(words[prev], words[index])) {
            take = 1 + solve(words, index + 1, index, dp);
        }

        int skip = solve(words, index + 1, prev, dp);

        return dp[index][prev + 1] = Math.max(take, skip);
    }

    private boolean isPredecessor(String small, String large) {

        if (large.length() != small.length() + 1)
            return false;

        int i = 0, j = 0;

        while (i < small.length() && j < large.length()) {

            if (small.charAt(i) == large.charAt(j)) {
                i++;
                j++;
            } else {
                j++;
            }
        }

        return i == small.length();
    }
}
```

---

## Complexity

- Time : **O(n² × L)**
- Space : **O(n²)**

# Approach 3 : Tabulation (1D DP) ✅ Optimal

## Idea

This is exactly the same idea as **LIS**.

Let

```text
dp[i]
```

be the length of the longest chain ending at word `i`.

Transition

```text
dp[i]

=

1 + dp[j]

if

words[j] is predecessor of words[i]
```

---

## Java Code

```java
import java.util.*;

class Solution {

    public int longestStrChain(String[] words) {

        Arrays.sort(words, (a, b) -> a.length() - b.length());

        int n = words.length;

        int[] dp = new int[n];
        Arrays.fill(dp, 1);

        int answer = 1;

        for (int i = 0; i < n; i++) {

            for (int j = 0; j < i; j++) {

                if (isPredecessor(words[j], words[i])) {

                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }

            answer = Math.max(answer, dp[i]);
        }

        return answer;
    }

    private boolean isPredecessor(String small, String large) {

        if (large.length() != small.length() + 1)
            return false;

        int i = 0;
        int j = 0;

        while (i < small.length() && j < large.length()) {

            if (small.charAt(i) == large.charAt(j)) {
                i++;
                j++;
            } else {
                j++;
            }
        }

        return i == small.length();
    }
}
```

# Comparison

| Approach | Time | Space |
|----------|------|--------|
| Brute Force Recursion | O(2ⁿ × L) | O(n) |
| Memoization | O(n² × L) | O(n²) |
| 1D DP (Optimal) | O(n² × L) | O(n) |

---

# Relationship with LIS

| Longest Increasing Subsequence | Longest String Chain |
|-------------------------------|----------------------|
| Compare numbers | Compare strings |
| `nums[j] < nums[i]` | `isPredecessor(words[j], words[i])` |
| Sort not required | Sort by length first |
| `dp[i]` = LIS ending at `i` | `dp[i]` = Longest chain ending at `i` |

---

# DP Pattern Learned

This is an **LIS Variant**.

State

```text
dp[i]

↓

Longest chain ending at i
```

Transition

```text
If words[j] is predecessor of words[i]

↓

dp[i]

=

max(

dp[i],

dp[j] + 1

)
```

---

# Key Interview Points

- Sort the words by **increasing length** before applying DP.
- A valid predecessor differs by **exactly one character**.
- Use a **two-pointer** method to check the predecessor relationship in **O(L)** time.
- This is a direct variation of the **Longest Increasing Subsequence** problem.
- The optimal solution uses **1D DP** with a time complexity of **O(n² × L)** and space complexity of **O(n)**.
