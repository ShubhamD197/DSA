# LeetCode 368 — Largest Divisible Subset

**Difficulty:** Medium  
**Topics:** Dynamic Programming, Sorting

---

## Problem Statement

Given a set of **distinct positive integers** `nums`, return the largest subset such that for every pair of elements `(answer[i], answer[j])`:

```text
answer[i] % answer[j] == 0
```

or:

```text
answer[j] % answer[i] == 0
```

If multiple valid answers exist, return any of them.

---

## Example 1

```text
Input:
nums = [1, 2, 3]

Output:
[1, 2]
```

Explanation:

```text
1 % 2 → 0
```

So `[1, 2]` is valid.

`[1, 3]` is also a valid answer.

---

## Example 2

```text
Input:
nums = [1, 2, 4, 8]

Output:
[1, 2, 4, 8]
```

Because:

```text
2 % 1 = 0
4 % 2 = 0
8 % 4 = 0
```

Every pair satisfies the divisibility condition.

---

# Main Idea

First, sort the array.

```text
nums = [1, 2, 4, 8]
```

After sorting:

```text
1 → 2 → 4 → 8
```

Now, if:

```java
nums[i] % nums[j] == 0
```

then `nums[i]` can be added after `nums[j]`.

This becomes similar to **Longest Increasing Subsequence (LIS)**.

But instead of checking:

```java
nums[i] > nums[j]
```

we check:

```java
nums[i] % nums[j] == 0
```

We also need to remember the previous index so that we can reconstruct the actual subset.

---

# DP State

We create:

```java
dp[i]
```

Meaning:

> The length of the largest divisible subset ending at `nums[i]`.

We also create:

```java
parent[i]
```

Meaning:

> The previous element/index used before `nums[i]`.

---

# Approach 1: Brute Force / Recursion

For every number, we have two choices:

```text
Take the number
```

or:

```text
Don't take the number
```

However, we need to keep track of the previous selected number to ensure divisibility.

The number of possible subsets is:

```text
2^n
```

So the brute-force approach is not practical for:

```text
n <= 1000
```

Therefore, we move to Dynamic Programming.

---

# Approach 2: DP — Length + Parent Reconstruction

## Java Code

```java
class Solution {
    public List<Integer> largestDivisibleSubset(int[] nums) {
        Arrays.sort(nums);

        int n = nums.length;

        int[] dp = new int[n];
        int[] parent = new int[n];

        Arrays.fill(dp, 1);

        int maxLength = 1;
        int lastIndex = 0;

        for (int i = 0; i < n; i++) {
            parent[i] = i;

            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    parent[i] = j;
                }
            }

            if (dp[i] > maxLength) {
                maxLength = dp[i];
                lastIndex = i;
            }
        }

        List<Integer> result = new ArrayList<>();

        while (parent[lastIndex] != lastIndex) {
            result.add(nums[lastIndex]);
            lastIndex = parent[lastIndex];
        }

        result.add(nums[lastIndex]);

        Collections.reverse(result);

        return result;
    }
}
```

# Why Do We Sort?

Suppose:

```text
nums = [8, 2, 4, 1]
```

After sorting:

```text
[1, 2, 4, 8]
```

Now every valid divisible chain can be built from smaller values to larger values.

For example:

```text
1 → 2 → 4 → 8
```

If:

```text
nums[i] % nums[j] == 0
```

then `nums[j]` is smaller than or equal to `nums[i]`.

This allows us to use the LIS-style DP approach.

---

# Why Is the Pairwise Condition Sufficient?

The problem says **every pair** in the subset must be divisible.

Suppose our subset is:

```text
[1, 2, 4, 8]
```

Because the numbers are sorted and every new number is divisible by the previous selected number:

```text
2 % 1 = 0
4 % 2 = 0
8 % 4 = 0
```

The divisibility relation is transitive:

```text
8 % 4 = 0
4 % 2 = 0
2 % 1 = 0
```

Therefore:

```text
8 % 2 = 0
8 % 1 = 0
4 % 1 = 0
```

So all pairs are valid.

# Complexity

Sorting:

```text
O(n log n)
```

DP:

```text
O(n²)
```

Overall:

```text
Time: O(n²)
Space: O(n)
```

The `O(n²)` DP dominates the sorting complexity.

# Final Recommended Solution

```java
class Solution {
    public List<Integer> largestDivisibleSubset(int[] nums) {
        Arrays.sort(nums);

        int n = nums.length;
        int[] dp = new int[n];
        int[] parent = new int[n];

        Arrays.fill(dp, 1);

        int maxLength = 1;
        int lastIndex = 0;

        for (int i = 0; i < n; i++) {
            parent[i] = i;

            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    parent[i] = j;
                }
            }

            if (dp[i] > maxLength) {
                maxLength = dp[i];
                lastIndex = i;
            }
        }

        List<Integer> result = new ArrayList<>();

        while (parent[lastIndex] != lastIndex) {
            result.add(nums[lastIndex]);
            lastIndex = parent[lastIndex];
        }

        result.add(nums[lastIndex]);
        Collections.reverse(result);

        return result;
    }
}
```

# Core Pattern to Remember

This problem is basically:

```text
Sort
  ↓
LIS-style DP
  ↓
Check divisibility instead of increasing order
  ↓
Store parent index
  ↓
Reconstruct the answer
```

The most important condition is:

```java
if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i])
```

Think of it as:

```text
Can nums[i] be added after nums[j]?
                ↓
       nums[i] % nums[j] == 0
                ↓
      Can it make a longer subset?
                ↓
          dp[j] + 1 > dp[i]
```

**Time:** `O(n²)`  
**Space:** `O(n)`
