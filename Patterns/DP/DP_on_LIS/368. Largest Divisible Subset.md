# Largest Divisible Subset

## Problem Statement

Given a set of distinct positive integers `nums[]`:

Return the **largest subset** such that for every pair:

```text id="vkhhmr"
a % b == 0
OR
b % a == 0
```

If multiple answers exist, return any one.

---

# Example

Input:

```text id="hbm6gr"
nums = [1,2,4,8]
```

Possible subset:

```text id="j8mj6y"
[1,2,4,8]
```

Why?

```text id="lgt9xt"
2 % 1 == 0
4 % 2 == 0
8 % 4 == 0
```

✅ Every pair is divisible.

---

# Key Observation

If:

```text id="iyq7y8"
a divides b
and
b divides c
```

Then:

```text id="3cq1eo"
a divides c
```

This means after sorting:

* divisible numbers naturally form a chain

---

# Main Idea

This problem is very similar to:

```text id="x00z2j"
Longest Increasing Subsequence (LIS)
```

Instead of:

```text id="xbx9mu"
nums[i] > nums[j]
```

We use:

```text id="r2gqpo"
nums[i] % nums[j] == 0
```

---

# DP Relation

For every index `i`:

dp[i]=1+\max(dp[j])\quad \text{where } j<i \text{ and } nums[i]\bmod nums[j]=0

---

# Approach

## Step 1

Sort the array.

Why?

```text id="dwl0jl"
Smaller divisors come before larger multiples.
```

---

## Step 2

Use DP:

```text id="8hb7ho"
dp[i] = size of largest divisible subset ending at i
```

---

## Step 3

Use a `parent/hash` array to reconstruct the subset.

---

# Time Complexity

```text id="5m7wul"
O(N²)
```

# Space Complexity


# Clean Java Solution

```java
import java.util.*;

class Solution {

    public List<Integer> largestDivisibleSubset(int[] nums) {

        Arrays.sort(nums);

        int n = nums.length;

        // dp[i] = length of largest divisible subset ending at i
        int[] dp = new int[n];

        // parent[i] = previous index in subset chain
        int[] parent = new int[n];

        Arrays.fill(dp, 1);

        int maxLength = 1;
        int lastIndex = 0;

        for (int current = 0; current < n; current++) {

            parent[current] = current;

            for (int prev = 0; prev < current; prev++) {

                // Divisibility condition
                if (nums[current] % nums[prev] == 0) {

                    // Better subset found
                    if (dp[prev] + 1 > dp[current]) {

                        dp[current] = dp[prev] + 1;

                        parent[current] = prev;
                    }
                }
            }

            // Track maximum subset length
            if (dp[current] > maxLength) {

                maxLength = dp[current];

                lastIndex = current;
            }
        }

        // Reconstruct answer
        List<Integer> answer = new ArrayList<>();

        while (parent[lastIndex] != lastIndex) {

            answer.add(nums[lastIndex]);

            lastIndex = parent[lastIndex];
        }

        answer.add(nums[lastIndex]);

        Collections.reverse(answer);

        return answer;
    }
}
```

# Small Optimization

Your original condition:

```java
nums[prev] % nums[idx] == 0 || nums[idx] % nums[prev] == 0
```

After sorting, you only need:

```java
nums[idx] % nums[prev] == 0
```

Because:

```text id="s2m49f"
nums[idx] >= nums[prev]
```

So only larger number can be divisible by smaller number.
