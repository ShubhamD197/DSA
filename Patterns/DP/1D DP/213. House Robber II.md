# 213. House Robber II

**Difficulty:** Medium

**Topic:** Dynamic Programming

---

# Problem Statement

You are a robber planning to rob houses arranged in a **circle**.

Each house contains some amount of money.

The only constraint is:

- You **cannot rob two adjacent houses**.
- Since the houses form a **circle**, the **first and last houses are also adjacent**.

Return the **maximum amount of money** you can rob.

---

# Key Observation

In **House Robber I**, houses are arranged in a straight line.

```text
1 - 2 - 3 - 4
```

In **House Robber II**, houses are arranged in a circle.

```text
      1

   /     \

  2       4

   \     /

      3
```

The first and last houses are adjacent.

Therefore,

```text
You cannot rob both.
```

---

# Breaking the Problem

There are only **two possible cases**.

### Case 1

Rob from

```text
House 0

to

House n-2
```

Do **not** consider the last house.

---

### Case 2

Rob from

```text
House 1

to

House n-1
```

Do **not** consider the first house.

---

Final Answer

```text
max(

Rob First to Second Last,

Rob Second to Last

)
```

---

# Approach 1 : Brute Force Recursion

## Idea

Solve both cases separately using recursion.

Take the maximum answer.

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1)
            return nums[0];

        return Math.max(
                solve(nums, 0, n - 2),
                solve(nums, 1, n - 1)
        );
    }

    private int solve(int[] nums, int index, int end) {

        if (index > end)
            return 0;

        int rob = nums[index] + solve(nums, index + 2, end);

        int skip = solve(nums, index + 1, end);

        return Math.max(rob, skip);
    }
}
```

# Approach 2 : Memoization (Top-Down DP)

## Idea

Memoize the recursive solution.

Since both cases are independent,

use separate DP arrays.

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1)
            return nums[0];

        int[] dp1 = new int[n];
        int[] dp2 = new int[n];

        Arrays.fill(dp1, -1);
        Arrays.fill(dp2, -1);

        int case1 = solve(nums, 0, n - 2, dp1);
        int case2 = solve(nums, 1, n - 1, dp2);

        return Math.max(case1, case2);
    }

    private int solve(int[] nums, int index, int end, int[] dp) {

        if (index > end)
            return 0;

        if (dp[index] != -1)
            return dp[index];

        int rob = nums[index] + solve(nums, index + 2, end, dp);

        int skip = solve(nums, index + 1, end, dp);

        dp[index] = Math.max(rob, skip);

        return dp[index];
    }
}
```

# Approach 3 : Tabulation (Bottom-Up DP)

## Idea

Run House Robber I twice.

Once excluding the last house.

Once excluding the first house.

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1)
            return nums[0];

        return Math.max(
                robRange(nums, 0, n - 2),
                robRange(nums, 1, n - 1)
        );
    }

    private int robRange(int[] nums, int start, int end) {

        int[] dp = new int[nums.length + 2];

        for (int i = end; i >= start; i--) {

            int rob = nums[i] + dp[i + 2];

            int skip = dp[i + 1];

            dp[i] = Math.max(rob, skip);
        }

        return dp[start];
    }
}
```

# Approach 4 : Space Optimized DP (Best)

## Idea

House Robber I can be optimized to **O(1)** space.

Simply run it twice.

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1)
            return nums[0];

        return Math.max(
                robRange(nums, 0, n - 2),
                robRange(nums, 1, n - 1)
        );
    }

    private int robRange(int[] nums, int start, int end) {

        int next1 = 0;
        int next2 = 0;

        for (int i = end; i >= start; i--) {

            int rob = nums[i] + next2;

            int skip = next1;

            int current = Math.max(rob, skip);

            next2 = next1;
            next1 = current;
        }

        return next1;
    }
}
```

# Why do we solve two cases?

Suppose

```text
nums = [2,3,2]
```

If we rob the **first house**,

we cannot rob the **last house**.

If we rob the **last house**,

we cannot rob the **first house**.

Therefore, one of them must be excluded.

The two possible linear ranges are:

```text
Case 1

0 → n-2

----------------

Case 2

1 → n-1
```

The maximum of these two cases is the final answer.

---

# Difference Between House Robber I and II

| House Robber I | House Robber II |
|---------------|-----------------|
| Houses are in a straight line | Houses are arranged in a circle |
| First and last houses are independent | First and last houses are adjacent |
| Solve once | Solve twice (exclude first or exclude last) |
| DP on one range | DP on two ranges |

---

# Key Interview Points

- House Robber II is an extension of **House Robber I**.
- Because the houses form a **circle**, the first and last houses cannot both be robbed.
- Break the problem into two independent linear DP problems:
  - Rob houses from `0` to `n-2`
  - Rob houses from `1` to `n-1`
- Use the same recurrence as House Robber I:

```text
dp[i] = max(nums[i] + dp[i+2], dp[i+1])
```

- The **space-optimized** solution is the preferred interview approach with **O(n)** time and **O(1)** space.
