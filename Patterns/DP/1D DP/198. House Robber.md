# 198. House Robber

**Difficulty:** Medium

**Topic:** Dynamic Programming

---

# Problem Statement

You are a robber planning to rob houses along a street.

Each house has some amount of money.

The only constraint is:

> You **cannot rob two adjacent houses** because the security system will automatically alert the police.

Return the **maximum amount of money** you can rob.

---

# Example 1

```text
Input

nums = [1,2,3,1]

Output

4
```

Explanation

```text
Rob house 1

↓

Money = 1

Rob house 3

↓

Money = 3

Total = 4
```

---

# Example 2

```text
Input

nums = [2,7,9,3,1]

Output

12
```

Explanation

```text
Rob

2 + 9 + 1

=

12
```

---

# Thinking Process (DP Pattern)

At every house we have **2 choices**.

### Choice 1 : Rob Current House

If we rob current house,

we **cannot rob previous house**.

```text
nums[i] + answer(i+2)
```

---

### Choice 2 : Skip Current House

```text
answer(i+1)
```

Therefore,

```text
answer(i) = max(

    nums[i] + answer(i+2),

    answer(i+1)

)
```

This recurrence is used in every approach.

---

# Approach 1 : Brute Force Recursion

## Idea

Try both possibilities at every house.

- Rob it
- Skip it

Return the maximum.

---

## Recursive Tree

Example

```text
nums = [2,7,9]
```

```text
f(0)

├── Rob 2

│      ↓

│     f(2)

│

└── Skip

       ↓

      f(1)
```

Notice

Many states are repeated.

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {
        return solve(nums, 0);
    }

    private int solve(int[] nums, int index) {

        if (index >= nums.length)
            return 0;

        int rob = nums[index] + solve(nums, index + 2);

        int skip = solve(nums, index + 1);

        return Math.max(rob, skip);
    }
}
```

---

## Dry Run

```text
nums = [2,7,9]
```

```

Rob

2 + solve(2)

↓

2 + 9 = 11

----------------

Skip

solve(1)

↓

max(7,9)

↓

9

Answer

max(11,9)

=

11
```

---

## Complexity

- Time : **O(2ⁿ)**
- Space : **O(n)**

# Approach 2 : Memoization (Top-Down DP)

## Idea

The recursive solution solves the same state multiple times.

Store every computed answer.

If already calculated,

return it directly.

---

## Java Code

```java
import java.util.Arrays;

class Solution {

    public int rob(int[] nums) {

        int[] dp = new int[nums.length];
        Arrays.fill(dp, -1);

        return solve(nums, 0, dp);
    }

    private int solve(int[] nums, int index, int[] dp) {

        if (index >= nums.length)
            return 0;

        if (dp[index] != -1)
            return dp[index];

        int rob = nums[index] + solve(nums, index + 2, dp);

        int skip = solve(nums, index + 1, dp);

        dp[index] = Math.max(rob, skip);

        return dp[index];
    }
}
```

---

## Dry Run

```text
nums = [2,7,9,3,1]
```

```text

[-1,-1,-1,-1,-1]
```

After solving

```text

[12,10,10,3,1]
```

Meaning

```text

Maximum money starting from index 0

dp[1] = 10

Maximum money starting from index 1

...
```

---

## Complexity

- Time : **O(n)**
- Space :
    - DP Array : **O(n)**
    - Recursion Stack : **O(n)**

Total

```text
O(n)
```

# Approach 3 : Tabulation (Bottom-Up DP)

## Idea

Instead of recursion,

build the answer from the end.

Transition

```text
dp[i] = max(

nums[i] + dp[i+2],

dp[i+1]

)
```

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {

        int n = nums.length;

        if (n == 1)
            return nums[0];

        int[] dp = new int[n + 2];

        for (int i = n - 1; i >= 0; i--) {

            int rob = nums[i] + dp[i + 2];

            int skip = dp[i + 1];

            dp[i] = Math.max(rob, skip);
        }

        return dp[0];
    }
}
```

---

# Approach 4 : Space Optimization

## Observation

DP only needs

```text
dp[i+1]

and

dp[i+2]
```

So instead of storing the whole array,

store only two variables.

---

## Java Code

```java
class Solution {

    public int rob(int[] nums) {

        int next1 = 0;
        int next2 = 0;

        for (int i = nums.length - 1; i >= 0; i--) {

            int rob = nums[i] + next2;

            int skip = next1;

            int current = Math.max(rob, skip);

            next2 = next1;
            next1 = current;
        }

        return next1;
    }
}
```

---

# DP Transition

```text
                i

                ↓

        +----------------+

        | Rob Current |

        +----------------+

nums[i] + dp[i+2]

                OR

        +----------------+

        | Skip Current |

        +----------------+

dp[i+1]

↓

Take Maximum
```

---

# Comparison

| Approach | Time | Space |
|----------|------|--------|
| Brute Force Recursion | O(2ⁿ) | O(n) |
| Memoization | O(n) | O(n) |
| Tabulation | O(n) | O(n) |
| Space Optimized DP | O(n) | O(1) |

---

# Why Space Optimization Works?

The recurrence is

```text
dp[i] = max(

nums[i] + dp[i+2],

dp[i+1]

)
```

Notice that to compute `dp[i]`, we only need:

- `dp[i+1]`
- `dp[i+2]`

Older DP values are never used again.

So instead of storing the entire DP array, we keep only two variables:

```text
next1 = dp[i+1]

next2 = dp[i+2]
```

This reduces the extra space from **O(n)** to **O(1)**.

---

# DP Pattern Learned

This problem introduces the classic **"Pick / Not Pick"** DP pattern.

At every index:

```text
Pick Current

↓

nums[i] + solve(i+2)

----------------

Skip Current

↓

solve(i+1)

----------------

Take Maximum
```

This same pattern appears in many DP problems such as:

- House Robber II (213)
- Delete and Earn (740)
- Maximum Sum of Non-Adjacent Elements
- Stickler Thief (GFG)

---

# Key Interview Points

- This is one of the most important introductory Dynamic Programming problems.
- The state is defined as: **maximum money that can be robbed starting from index `i`**.
- Recurrence:

```text
dp[i] = max(nums[i] + dp[i+2], dp[i+1])
```

- Brute force explores both choices recursively.
- Memoization eliminates repeated subproblems.
- Tabulation builds the answer from the end.
- Since only `dp[i+1]` and `dp[i+2]` are needed, the solution can be optimized to **O(1)** space.
