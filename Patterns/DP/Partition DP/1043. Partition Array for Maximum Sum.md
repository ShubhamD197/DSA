# Partition Array for Maximum Sum

## Problem Statement

Given an integer array `arr[]` and an integer `k`:

* Divide the array into contiguous subarrays
* Each subarray can have **maximum length = k**
* Replace every element of a subarray with the **maximum element** of that subarray

Return the **maximum possible sum** after partitioning.

---

# Example

Input:

```text
arr = [1,15,7,9,2,5,10]
k = 3
```

Possible optimal partition:

```text
[1,15,7] [9] [2,5,10]
```

After replacing with maximums:

```text
[15,15,15] [9] [10,10,10]
```

Final Sum:

```text
45 + 9 + 30 = 84
```

✅ Output = `84`

---

# Intuition

At every index:

```text
Should I take:
1 element?
2 elements?
3 elements?
...
up to k elements?
```

For every partition:

* Find the maximum element
* Multiply it by partition length
* Add answer of remaining array

We try all possibilities and take the maximum.

---

# Recursive Relation

If we start from index `i`:

dp[i]=\max\left(\text{maxElement}\times \text{length}+dp[i+\text{length}]\right)

---

# Memoization (Top Down DP)

## Time Complexity

```text
O(N × K)
```

## Space Complexity

```text

```

# Clean Java Solution

```java
import java.util.Arrays;

class Solution {

    public int maxSumAfterPartitioning(int[] arr, int k) {

        int n = arr.length;

        // dp[i] = maximum sum starting from index i
        int[] dp = new int[n];

        Arrays.fill(dp, -1);

        return solve(0, arr, k, dp);
    }

    private int solve(int start, int[] arr, int k, int[] dp) {

        // Base Case:
        // Reached end of array
        if (start == arr.length) {
            return 0;
        }

        // Already calculated
        if (dp[start] != -1) {
            return dp[start];
        }

        int maxAnswer = 0;
        int currentMax = 0;

        // Try all partition lengths from 1 → k
        for (int len = 1; len <= k && start + len <= arr.length; len++) {

            // Update maximum element of current partition
            currentMax = Math.max(currentMax, arr[start + len - 1]);

            // Current partition contribution
            int partitionSum = currentMax * len;

            // Remaining array answer
            int remaining = solve(start + len, arr, k, dp);

            // Total answer
            int total = partitionSum + remaining;

            maxAnswer = Math.max(maxAnswer, total);
        }

        return dp[start] = maxAnswer;
    }
}
```

* partition maximum
* partition length
* best future answer

# Bottom Up (Tabulation)

```java
import java.util.*;

class Solution {

    public int maxSumAfterPartitioning(int[] arr, int k) {

        int n = arr.length;

        int[] dp = new int[n + 1];

        // Build from back
        for (int start = n - 1; start >= 0; start--) {

            int maxAnswer = 0;
            int currentMax = 0;

            for (int len = 1; len <= k && start + len <= n; len++) {

                currentMax = Math.max(currentMax, arr[start + len - 1]);

                int total =
                        currentMax * len +
                        dp[start + len];

                maxAnswer = Math.max(maxAnswer, total);
            }

            dp[start] = maxAnswer;
        }

        return dp[0];
    }
}
```
