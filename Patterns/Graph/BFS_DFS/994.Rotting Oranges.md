# LeetCode 994 — Rotting Oranges

**Difficulty:** Medium  
**Topics:** BFS, Queue, Matrix

---

## Problem Statement

You are given a grid where:

```text
0 = Empty cell
1 = Fresh orange
2 = Rotten orange
```

Every minute, a rotten orange makes all **adjacent fresh oranges** rotten.

Adjacent means:

```text
Up
Down
Left
Right
```

Return the **minimum number of minutes** until no fresh oranges remain.

If it is impossible to rot all fresh oranges, return:

```text
-1
```

# Main Idea

This is a classic **Multi-Source BFS** problem.

Why?

Because multiple rotten oranges can start spreading at the same time.

For example:

```text
2 1 1
1 1 1
1 1 2
```

Both rotten oranges start spreading simultaneously.

So we put **all rotten oranges into the queue initially**.

Then process the queue level by level.

Each BFS level represents:

```text
1 minute
```

---

# Approach 1: Brute Force / Simulation

One possible approach is to repeatedly scan the entire grid.

For every minute:

1. Find all rotten oranges.
2. Rot their neighboring fresh oranges.
3. Repeat until no more oranges can rot.

The problem is that repeatedly scanning the whole grid can be inefficient and also requires careful handling to make sure oranges that rot in the same minute don't immediately spread again in that same minute.

BFS naturally handles this using levels.

So BFS is the preferred solution.

---

# Approach 2: Multi-Source BFS

## Step 1: Add all rotten oranges

While traversing the grid:

```text
If grid[i][j] == 2
    Add it to queue
```

Also count the number of fresh oranges.

For example:

```text
2 1 1
1 1 0
0 1 1
```

Queue initially:

```text
[(0,0)]
```

Fresh oranges:

```text
6
```

---

## Step 2: Process One BFS Level

At the beginning of each minute, the queue contains all oranges that became rotten during the previous minute.

For every rotten orange:

```text
Check:
Up
Down
Left
Right
```

If a neighbor is fresh:

```java
grid[nr][nc] = 2;
fresh--;
queue.offer(new int[]{nr, nc});
```

---

## Step 3: Increase Time

After processing all oranges currently in the queue:

```java
minutes++;
```

This means one minute has passed.

---

## Step 4: Check Remaining Fresh Oranges

At the end:

```text
If fresh == 0 → return minutes
Otherwise → return -1
```

---

# Java Code

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;

        Queue<int[]> queue = new LinkedList<>();
        int fresh = 0;

        // Add all rotten oranges to the queue
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        int minutes = 0;
        int[][] directions = {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        while (!queue.isEmpty() && fresh > 0) {
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                int[] current = queue.poll();

                int row = current[0];
                int col = current[1];

                for (int[] direction : directions) {
                    int newRow = row + direction[0];
                    int newCol = col + direction[1];

                    if (newRow >= 0 && newRow < rows &&
                        newCol >= 0 && newCol < cols &&
                        grid[newRow][newCol] == 1) {

                        grid[newRow][newCol] = 2;
                        fresh--;

                        queue.offer(new int[]{newRow, newCol});
                    }
                }
            }

            minutes++;
        }

        return fresh == 0 ? minutes : -1;
    }
}
```

# Why `size = queue.size()` Is Important

This is the most important part of the BFS:

```java
int size = queue.size();

for (int i = 0; i < size; i++) {
    ...
}

minutes++;
```

Suppose initially:

```text
Queue = [A]
```

At minute 1, `A` makes:

```text
B, C
```

rotten.

They are added to the queue:

```text
Queue = [B, C]
```

But `B` and `C` should spread only in **minute 2**, not minute 1.

That's why we save:

```java
int size = queue.size();
```

We process only the oranges that were already rotten at the beginning of the current minute.

Newly rotten oranges wait for the next BFS level.

# Approach 3: BFS Without Explicit Time Levels

We can also store the time along with each cell.

Instead of:

```java
Queue<int[]> queue
```

we store:

```text
row
col
time
```

For example:

```text
[0, 0, 0]
```

means:

```text
row = 0
col = 0
time = 0
```

When we rot a neighbor:

```text
new time = current time + 1
```

---

## Java Code

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;

        Queue<int[]> queue = new LinkedList<>();
        int fresh = 0;
        int minutes = 0;

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j, 0});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        int[][] directions = {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        while (!queue.isEmpty()) {
            int[] current = queue.poll();

            int row = current[0];
            int col = current[1];
            int time = current[2];

            minutes = Math.max(minutes, time);

            for (int[] direction : directions) {
                int newRow = row + direction[0];
                int newCol = col + direction[1];

                if (newRow >= 0 && newRow < rows &&
                    newCol >= 0 && newCol < cols &&
                    grid[newRow][newCol] == 1) {

                    grid[newRow][newCol] = 2;
                    fresh--;

                    queue.offer(new int[]{newRow, newCol, time + 1});
                }
            }
        }

        return fresh == 0 ? minutes : -1;
    }
}
```

# Which Approach Is Better?

I recommend the **Multi-Source BFS with level-by-level processing**.

The main pattern is:

```text
Put all starting points in Queue
              ↓
Process one level
              ↓
One level = One minute
              ↓
Spread to neighbors
              ↓
Process next level
```

It is clean and avoids storing the time for every cell.

# Core Pattern to Remember

This problem is a classic **Multi-Source BFS**.

```text
Multiple starting points
        ↓
Add all to Queue initially
        ↓
BFS
        ↓
Each level represents one unit of time
        ↓
Spread to adjacent cells
```

The key code is:

```java
while (!queue.isEmpty() && fresh > 0) {
    int size = queue.size();

    for (int i = 0; i < size; i++) {
        // Process current level
    }

    minutes++;
}
```

**Time Complexity:** `O(m × n)`  
**Space Complexity:** `O(m × n)`
