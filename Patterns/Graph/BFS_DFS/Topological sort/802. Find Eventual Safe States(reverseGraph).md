# LeetCode 802 — Find Eventual Safe States

**Difficulty:** Medium  
**Topics:** Graph, DFS, BFS, Topological Sort

---

## Problem Statement

You are given a **directed graph** where:

```text
graph[i]
```

contains all nodes that can be visited directly from node `i`.

A node is called **safe** if every possible path starting from that node eventually ends at a **terminal node**.

A **terminal node** is a node with:

```text
No outgoing edges
```

Return all safe nodes in **ascending order**.

# Main Idea

A node is **unsafe** if:

```text
It is part of a cycle

OR

It can reach a cycle.
```

A node is **safe** if:

```text
Every path eventually reaches
a terminal node.
```

So the problem becomes:

```text
Find all nodes that are NOT connected
to any cycle.
```

---

# Approach 1: DFS Cycle Detection

We use three states:

```text
0 = Unvisited
1 = Visiting
2 = Safe (Visited)
```

If during DFS we revisit a node in state `1`:

```text
Cycle found
```

That node is unsafe.

Only after all neighbors are safe can we mark the current node as safe.

---

## Java Code

```java
class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;

        int[] state = new int[n];

        List<Integer> answer = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            if (isSafe(i, graph, state)) {
                answer.add(i);
            }
        }

        return answer;
    }

    private boolean isSafe(int node, int[][] graph, int[] state) {
        if (state[node] != 0) {
            return state[node] == 2;
        }

        state[node] = 1;

        for (int next : graph[node]) {
            if (!isSafe(next, graph, state)) {
                return false;
            }
        }

        state[node] = 2;

        return true;
    }
}
```

# Approach 2: BFS (Reverse Graph + Topological Sort) ⭐ Recommended

Instead of finding unsafe nodes, we find safe nodes.

Observation:

```text
Terminal nodes
```

are always safe.

If all outgoing edges of a node point to safe nodes,

then that node also becomes safe.

### Steps

1. Reverse the graph.
2. Store outdegree of every node.
3. Terminal nodes have:

```text
outdegree = 0
```

4. Push them into a queue.
5. Remove one node at a time.
6. Reduce outdegree of its parents.
7. If parent's outdegree becomes `0`, it is also safe.

---

## Java Code

```java
class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;

        List<List<Integer>> reverse = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            reverse.add(new ArrayList<>());
        }

        int[] outDegree = new int[n];

        for (int i = 0; i < n; i++) {
            outDegree[i] = graph[i].length;

            for (int next : graph[i]) {
                reverse.get(next).add(i);
            }
        }

        Queue<Integer> queue = new LinkedList<>();

        for (int i = 0; i < n; i++) {
            if (outDegree[i] == 0) {
                queue.offer(i);
            }
        }

        List<Integer> safe = new ArrayList<>();

        while (!queue.isEmpty()) {
            int node = queue.poll();

            safe.add(node);

            for (int parent : reverse.get(node)) {
                outDegree[parent]--;

                if (outDegree[parent] == 0) {
                    queue.offer(parent);
                }
            }
        }

        Collections.sort(safe);

        return safe;
    }
}
```

# Why Reverse the Graph?

Original graph:

```text
0 → 1 → 2
```

Terminal node:

```text
2
```

We already know:

```text
2 is safe
```

Now we want to know:

```text
Who points to 2?
```

That's easier using the **reverse graph**:

```text
2 → 1 → 0
```

Now we move **backwards**, marking parents as safe.

# Why is BFS Recommended?

The BFS approach avoids recursion and directly starts from:

```text
Terminal Nodes
```

Then it propagates safety backwards using the reverse graph.

It's also easier to understand once you're familiar with **Kahn's Algorithm**.

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;

        List<List<Integer>> reverse = new ArrayList<>();

        for (int i = 0; i < n; i++) {
            reverse.add(new ArrayList<>());
        }

        int[] outDegree = new int[n];

        for (int i = 0; i < n; i++) {
            outDegree[i] = graph[i].length;

            for (int next : graph[i]) {
                reverse.get(next).add(i);
            }
        }

        Queue<Integer> queue = new LinkedList<>();

        for (int i = 0; i < n; i++) {
            if (outDegree[i] == 0) {
                queue.offer(i);
            }
        }

        List<Integer> safe = new ArrayList<>();

        while (!queue.isEmpty()) {
            int node = queue.poll();

            safe.add(node);

            for (int parent : reverse.get(node)) {
                outDegree[parent]--;

                if (outDegree[parent] == 0) {
                    queue.offer(parent);
                }
            }
        }

        return safe;
    }
}

# Core Pattern to Remember

This problem is:

```text
Directed Graph
        ↓
Find Nodes That Never Reach a Cycle
```

### DFS Idea

```text
Visit Node
      ↓
Visit Neighbors
      ↓
Cycle Found?
      ↓
No → Safe
Yes → Unsafe
```

### BFS Idea

```text
Terminal Nodes
        ↓
Reverse Graph
        ↓
Reduce Parents' Outdegree
        ↓
Outdegree becomes 0
        ↓
Parent is Safe
```
