# LeetCode 207 — Course Schedule

**Difficulty:** Medium  
**Topics:** Graph, DFS, BFS, Topological Sort

---

## Problem Statement

There are `numCourses` courses labeled from:

```text
0 to numCourses - 1
```

You are given:

```text
prerequisites[i] = [a, b]
```

which means:

```text
To take course a,
you must first complete course b.
```

Return:

```text
true
```

if it is possible to finish all courses, otherwise return:

```text
false
```

# Main Idea

This problem asks:

```text
Can every course be completed?
```

A course cannot be completed if its prerequisites form a **cycle**.

Example:

```text
0 → 1 → 2 → 0
```

To complete:

```text
0
```

you need:

```text
2
```

To complete:

```text
2
```

you need:

```text
1
```

To complete:

```text
1
```

you need:

```text
0
```

Impossible.

So the problem reduces to:

```text
Detect a cycle in a directed graph.
```

---

# Approach 1: DFS Cycle Detection

During DFS every node can be in three states:

```text
0 = Not Visited
1 = Visiting (current recursion stack)
2 = Visited
```

If during DFS we visit a node that is already:

```text
Visiting
```

then we found a cycle.

---

## Java Code

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();

        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }

        for (int[] edge : prerequisites) {
            graph.get(edge[1]).add(edge[0]);
        }

        int[] state = new int[numCourses];

        for (int i = 0; i < numCourses; i++) {
            if (hasCycle(i, graph, state)) {
                return false;
            }
        }

        return true;
    }

    private boolean hasCycle(int node, List<List<Integer>> graph, int[] state) {
        if (state[node] == 1) return true;
        if (state[node] == 2) return false;

        state[node] = 1;

        for (int next : graph.get(node)) {
            if (hasCycle(next, graph, state)) {
                return true;
            }
        }

        state[node] = 2;

        return false;
    }
}
```

# Approach 2: BFS (Kahn's Algorithm)

Instead of detecting a cycle directly, we perform a **Topological Sort**.

Steps:

1. Compute indegree of every node.
2. Add all nodes with indegree `0` to a queue.
3. Remove them one by one.
4. Reduce indegree of neighbors.
5. If all nodes are processed → no cycle.

If some nodes are never processed:

```text
Cycle exists.
```

---

## Java Code

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>();

        for (int i = 0; i < numCourses; i++) {
            graph.add(new ArrayList<>());
        }

        int[] indegree = new int[numCourses];

        for (int[] edge : prerequisites) {
            graph.get(edge[1]).add(edge[0]);
            indegree[edge[0]]++;
        }

        Queue<Integer> queue = new LinkedList<>();

        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }

        int completed = 0;

        while (!queue.isEmpty()) {
            int course = queue.poll();
            completed++;

            for (int next : graph.get(course)) {
                indegree[next]--;

                if (indegree[next] == 0) {
                    queue.offer(next);
                }
            }
        }

        return completed == numCourses;
    }
}
```

# Why Does Kahn's Algorithm Detect Cycles?

Nodes inside a cycle always have:

```text
indegree > 0
```

Example:

```text
0 → 1
↑   |
|   ↓
└───2
```

Indegree:

```text
0 = 1
1 = 1
2 = 1
```

Queue:

```text
[]
```

No node has indegree `0`.

No course can be processed.

So:

```text
completed < numCourses
```

Cycle exists.

|---|---:|---:|---|
| DFS Cycle Detection | O(V + E) | O(V) | Best for cycle detection |
| BFS (Kahn's Algorithm) | O(V + E) | O(V) | Best for topological ordering |

---

# Which Approach Is Better?

Both are optimal.

- Use **DFS** if the question asks to **detect a cycle**.
- Use **BFS (Kahn's Algorithm)** if the question asks for a **topological order** or to determine if all courses can be completed.

In interviews, knowing **both approaches** is recommended.

# Core Pattern to Remember

This problem is essentially:

```text
Course Prerequisites
        ↓
Directed Graph
        ↓
Need to finish every course
        ↓
No Cycle Allowed
```

### DFS Pattern

```text
0 = Unvisited
1 = Visiting
2 = Visited

If we visit a node already marked Visiting,
a cycle exists.
```

### BFS Pattern

```text
Calculate indegree
        ↓
Push all indegree = 0 nodes
        ↓
Process queue
        ↓
Decrease neighbors' indegree
        ↓
If processed nodes == total nodes
        ↓
No cycle
```
