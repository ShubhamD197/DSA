# 904. Fruit Into Baskets

**Difficulty:** Medium

**Topic:** Sliding Window / Two Pointers / HashMap

---

# Problem Statement

You are given an integer array `fruits` where:

```text
fruits[i]
```

represents the type of fruit on the `i-th` tree.

You have **two baskets**.

Each basket can hold only **one type of fruit**, but it can hold any number of fruits of that type.

You start from any tree and move only to the right.

You must pick exactly one fruit from every tree you visit.

You must stop when you reach a tree whose fruit type cannot be placed into either basket.

Return the **maximum number of fruits** you can collect.

In simple words:

> Find the longest contiguous subarray containing at most **2 distinct numbers**.

# Approach 1: Brute Force

## Idea

Start from every possible index and expand the subarray.

For each starting position:

1. Create a `HashSet`.
2. Add elements one by one.
3. Stop when we have more than `2` distinct fruit types.
4. Keep track of the maximum length.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int totalFruit(int[] fruits) {

        int n = fruits.length;
        int maxLength = 0;

        for (int i = 0; i < n; i++) {

            Set<Integer> set = new HashSet<>();

            for (int j = i; j < n; j++) {

                set.add(fruits[j]);

                // More than 2 fruit types
                if (set.size() > 2) {
                    break;
                }

                maxLength = Math.max(
                        maxLength,
                        j - i + 1
                );
            }
        }

        return maxLength;
    }
}
```

# Approach 2: Sliding Window with HashMap

## Idea

Instead of starting from every index, we maintain a window:

```text
[left ... right]
```

The window must always contain at most `2` distinct fruit types.

We use a `HashMap` to store:

```text
fruit type → frequency
```

Steps:

1. Expand the window using `right`.
2. Add the current fruit to the map.
3. If the map contains more than `2` types:
   - Remove `fruits[left]`.
   - Decrease its frequency.
   - Move `left`.
4. Update the maximum window size.

---

## Java Code

```java
import java.util.*;

class Solution {

    public int totalFruit(int[] fruits) {

        Map<Integer, Integer> map = new HashMap<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < fruits.length; right++) {

            // Add current fruit
            map.put(
                    fruits[right],
                    map.getOrDefault(fruits[right], 0) + 1
            );

            // More than 2 fruit types
            while (map.size() > 2) {

                int fruit = fruits[left];

                map.put(
                        fruit,
                        map.get(fruit) - 1
                );

                // Remove fruit type completely
                if (map.get(fruit) == 0) {
                    map.remove(fruit);
                }

                left++;
            }

            // Current window is valid
            maxLength = Math.max(
                    maxLength,
                    right - left + 1
            );
        }

        return maxLength;
    }
}
```

# Approach 3: Sliding Window with HashMap and Last Occurrence

## Idea

We can optimize the shrinking process.

Instead of storing the frequency of every fruit, we store:

```text
fruit → last index where it appeared
```

When we get a third fruit type, we need to remove one of the existing two types.

To make the window as large as possible, we remove the fruit whose **last occurrence is farthest to the left**.

Suppose:

```text
Window:
[1,2,1,2,3]
```

The two existing fruit types are:

```text
1 → last occurrence at index 2
2 → last occurrence at index 3
```

When `3` arrives, we remove `1` because its last occurrence is earlier.

New window:

```text
[2,1,2,3]
```

After removing everything up to the last occurrence of `1`, we get:

```text
[2,3]
```

Actually, we set:

```text
left = lastIndexOfRemovedFruit + 1
```

So:

```text
left = 2 + 1
     = 3
```

New window:

```text
[2,3]
```

---

## Java Code

```java
import java.util.*;

class Solution {

    public int totalFruit(int[] fruits) {

        Map<Integer, Integer> lastIndex = new HashMap<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < fruits.length; right++) {

            // Store latest occurrence
            lastIndex.put(
                    fruits[right],
                    right
            );

            // More than 2 fruit types
            if (lastIndex.size() > 2) {

                int firstFruit = -1;
                int secondFruit = -1;

                for (int fruit : lastIndex.keySet()) {

                    if (firstFruit == -1 ||
                        lastIndex.get(fruit) <
                        lastIndex.get(firstFruit)) {

                        secondFruit = firstFruit;
                        firstFruit = fruit;

                    } else {
                        secondFruit = fruit;
                    }
                }

                // Remove fruit with earliest last occurrence
                lastIndex.remove(firstFruit);

                left = lastIndex.get(secondFruit) + 1;
            }

            maxLength = Math.max(
                    maxLength,
                    right - left + 1
            );
        }

        return maxLength;
    }
}
```

# Better Version of Approach 3

Because there are only two fruit types in the map, we can directly find the fruit with the smallest last occurrence.

```java
import java.util.*;

class Solution {

    public int totalFruit(int[] fruits) {

        Map<Integer, Integer> lastIndex = new HashMap<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < fruits.length; right++) {

            lastIndex.put(fruits[right], right);

            if (lastIndex.size() > 2) {

                int minIndex = Integer.MAX_VALUE;
                int fruitToRemove = -1;

                for (int fruit : lastIndex.keySet()) {

                    if (lastIndex.get(fruit) < minIndex) {
                        minIndex = lastIndex.get(fruit);
                        fruitToRemove = fruit;
                    }
                }

                lastIndex.remove(fruitToRemove);

                left = minIndex + 1;
            }

            maxLength = Math.max(
                    maxLength,
                    right - left + 1
            );
        }

        return maxLength;
    }
}
```

# Approach 4: Optimal Sliding Window with Two Fruit Types

## Idea

Since we only need to keep track of **two fruit types**, we don't actually need a `HashMap`.

We can maintain:

```text
fruit1
fruit2
```

and their latest positions.

When a third fruit appears:

1. The current fruit becomes one type.
2. The previous fruit becomes the second type.
3. Move `left` to the position after the last occurrence of the fruit that is no longer useful.

This gives an `O(n)` solution with `O(1)` extra space.

---

## Java Code

```java
class Solution {

    public int totalFruit(int[] fruits) {

        int left = 0;
        int maxLength = 0;

        int fruit1 = -1;
        int fruit2 = -1;

        int lastFruit2Index = -1;

        for (int right = 0; right < fruits.length; right++) {

            int current = fruits[right];

            // Same as fruit2
            if (current == fruit2) {

                lastFruit2Index = right;

            }

            // New fruit type
            else if (current != fruit1) {

                // Move left after the last occurrence
                // of the old second fruit
                left = lastFruit2Index + 1;

                // Old fruit2 becomes fruit1
                fruit1 = fruit2;

                // Current fruit becomes fruit2
                fruit2 = current;

                // Current fruit's last index
                lastFruit2Index = right;
            }

            maxLength = Math.max(
                    maxLength,
                    right - left + 1
            );
        }

        return maxLength;
    }
}
```

# Important Note

The compact two-variable implementation is easy to get wrong because the variables represent **the two most recently relevant fruit types**, not simply "first fruit" and "second fruit".

For interviews and production code, the **HashMap frequency solution** is usually the clearest and safest.

# Which Approach Is Better?

## Best for Learning: Brute Force

The brute-force approach makes the problem easy to understand:

```text
Try every starting point
        ↓
Expand window
        ↓
Stop when 3 types appear
```

But it is:

```text
O(n²)
```

so it is not the preferred solution.

---

## Best Overall: Sliding Window + HashMap

The HashMap solution is the best balance between:

- Simplicity
- Readability
- Efficiency

The core logic is:

```java
while (map.size() > 2) {
    // Remove from left
}
```

Each element enters the window once and leaves the window once.

Therefore:

```text
Time: O(n)
```

---

## Most Space Efficient: Two-Type Sliding Window

If we know that we only need exactly two fruit types, we can track them using variables.

This gives:

```text
Time: O(n)
Space: O(1)
```

However, it is more difficult to understand and implement correctly.

# Why Is Sliding Window O(n)?

At first, it may look like:

```text
for right
    while (...)
        left++
```

which might seem like `O(n²)`.

But `left` never moves backward.

For example:

```text
right → 0 1 2 3 4 5
left  → 0 0 0 1 2 2
```

Across the entire algorithm:

```text
right moves at most n times
left moves at most n times
```

Therefore:

```text
O(n) + O(n)
= O(n)
```

---

# Core Sliding Window Pattern

```text
Initialize left = 0

for right = 0 to n - 1:

    Add fruits[right]

    while window is invalid:

        Remove fruits[left]

        left++

    Update maximum window size
```

For this problem:

```text
Window is valid
    ↓
At most 2 distinct fruit types
```

So the key condition is:

```java
while (map.size() > 2)
```

---

# Key Interview Takeaways

- This is a classic **Sliding Window** problem.
- The problem can be converted to:
  
```text
Find the longest subarray with at most 2 distinct elements.
```

- `right` expands the window.
- `left` shrinks the window.
- Use a `HashMap` to track fruit frequencies.
- If there are more than `2` fruit types, shrink from the left.
- Each element is added and removed at most once.
- Therefore, the optimal time complexity is:

```text
O(n)
```

- Since at most `3` types exist temporarily in the HashMap, auxiliary space is:

```text
O(1)
```

- The most important condition is:

```java
while (map.size() > 2)
```

- The core pattern is:

```text
Expand
   ↓
Invalid?
   ↓
Shrink
   ↓
Update Answer
```

# Final Recommended Code

```java
import java.util.*;

class Solution {

    public int totalFruit(int[] fruits) {

        Map<Integer, Integer> map = new HashMap<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < fruits.length; right++) {

            // Add current fruit to the window
            map.put(
                    fruits[right],
                    map.getOrDefault(fruits[right], 0) + 1
            );

            // Window contains more than 2 fruit types
            while (map.size() > 2) {

                int fruit = fruits[left];

                // Remove fruit from left side
                map.put(
                        fruit,
                        map.get(fruit) - 1
                );

                // Remove type if no occurrences remain
                if (map.get(fruit) == 0) {
                    map.remove(fruit);
                }

                left++;
            }

            // Update maximum valid window
            maxLength = Math.max(
                    maxLength,
                    right - left + 1
            );
        }

        return maxLength;
    }
}
```
